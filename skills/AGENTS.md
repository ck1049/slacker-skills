# 技能同步与版本交付

适用于本目录内的技能维护；用户对本次任务的明确要求优先。

- 每次获授权修改并同步技能后，将该次逻辑变更独立提交，并推送到各受影响 Git 仓库已配置的对应远端分支；核对远端提交 SHA 后才报告同步交付完成，不把提交推送留到多轮修改累积后处理。
- 提交前检查工作区、暂存区和未推送历史，只纳入本次变更。文件含其他未提交修改时按变更块暂存，保留其他内容；不得使用全量暂存把无关改动带入提交。多个独立改动分别提交，便于回退。
- 同步项目技能目录、Codex 全局目录和技能仓库中约定的对应副本，核对本次变更一致。没有独立 Git 仓库的全局目录通过源仓库提交和同步校验追溯，不另建仓库。
- 推送失败、远端领先、存在不属于本次任务的未推送提交或发布权限不明时，查清并保留已完成的同步与提交，不强推、不覆盖远端、不盲目推送无关提交；说明准确阻塞，不将本地提交报告为已推送。
- 交付简报包含修改范围、校验结果、各仓库提交号及推送/远端核验状态。
