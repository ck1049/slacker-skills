# 后端接口质量

## 建立本次边界

先读取任务、仓库规则、路由/协议定义、相邻业务模块、错误处理及测试入口。确认消费者、认证方式、数据归属、持久化技术和兼容性要求。记录工作区旧改动，保持本需求可单独审查；不擅自提交、清理或改写它们。

优先使用现有框架和约定。本技能提供检查路径，不强制某语言、Controller/Service 命名、统一响应外壳、HTTP 200 或固定部署架构。已确认的产品决策不重复询问；缺失信息会改变权限、付费、破坏兼容或数据生命周期时，明确提出所缺决策。

## 实现与审查路径

### 契约和错误

- 已知结构的输入、输出、分页、操作结果采用语言中明确的数据类型，并在信任边界执行运行时校验；动态字典才使用开放 Map。明确缺省值、可空、范围、时区、单位及未知字段策略。
- 业务错误集中定义稳定标识与安全描述，由协议边界统一映射；避免各路由复制字符串或自行拼接错误结构。校验、认证过滤器及未捕获异常也核对一致性，但不吞掉诊断信息或暴露栈与秘密。
- HTTP 接口保持状态码与实际语义一致；不能把统一业务错误等同于所有响应必须 200。沿用兼容的响应契约，按需要评估 Problem Details；文件流、SSE、健康检查等保留自己的协议，勿强行包成 JSON。
- 修改契约时同步实际使用的 schema、DTO、客户端类型和行为测试。OpenAPI 适用于 HTTP；其他协议使用对应 IDL/schema。生成代码由原始定义再生成，不直接修补产物。

### 职责和数据边界

- 协议层负责解析、认证上下文与响应，业务层负责规则与操作边界，数据访问层封装持久化。小型服务允许简洁结构，不能用空壳层和循环依赖制造分层假象。
- 查询、更新、删除均检查用户/租户归属；资源 ID 或前端隐藏按钮不是授权。控制允许写入的字段，避免批量赋值越权；列表分页和排序使用界限与白名单。
- 事务覆盖必须一起成功的本地变化；验证锁、唯一约束、条件更新、回滚与隔离级别。不要用“先查再写”替代原子竞争控制，不能在改用通用 CRUD 时丢失条件更新语义。
- 避免在长事务中等待网络。数据库事务不能自动回滚外部副作用；按现有架构选择补偿、持久任务、outbox 或可恢复状态，只有真实需求才增加这些机制。

### 重试、外部调用与运行质量

- 为需防重复的操作定义幂等键作用域、请求一致性、有效期及结果复用。相同键不同请求不可误认同一次操作；测试并发重复请求，而不只顺序执行两遍。
- 外部请求超时可能已成功。涉及收费或不可逆副作用时保留未知状态并通过已支持查询恢复；没有证据不得盲目重发。检查 SDK、客户端和队列的多层隐式重试，不承诺未经证明的端到端恰好一次。
- 超时、取消、连接与响应大小有明确边界。日志使用可关联标识并脱敏；已知敏感字段不能进入响应或日志。并发、分页、批量与 N+1 风险用实际调用路径或测量证明，避免无依据优化。

## 验证与改进

优先执行仓库已有命令，不假定容器、数据库或工具已就绪。按改动风险选择：契约成功/错误、非法输入、未认证、跨用户读取和写入、事务回滚、竞争更新、重复提交以及外部未知结果。用真实目标数据库验证依赖其锁/隔离/方言的行为；替代数据库和 mock 的通过不能证明这些语义。

给发现附上文件位置、触发条件、影响和复现证据。先修确认的正确性、隔离、重复副作用问题，再处理职责混杂、重复规则、复杂度与测试薄弱点。范围内修复后复测复查；报告尚未解决项及理由，不把建议数量当质量结论。语言 formatter/linter、构建、行为测试与审查互补，任何一种都不能替代其他层面。

执行需要凭据、费用、生产数据或外部发送时，先确认任务授权范围；技能本身不授予这些权限。未运行的测试、未接入的真实服务以及模拟证据必须明确说明。

## 官方依据

- [RFC 9110 HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110.html)：HTTP 方法、状态与幂等语义；业务副作用仍须实现层验证。
- [RFC 9457 Problem Details](https://www.rfc-editor.org/rfc/rfc9457.html)：可选的 HTTP 错误表达契约，不强制迁移已有接口。
- [OpenAPI Specification](https://spec.openapis.org/oas/latest.html)：核对项目工具支持的版本后使用，不因最新规范自动升级。
- [Spring 事务实现](https://docs.spring.io/spring-framework/reference/data-access/transaction/declarative/tx-decl-explained.html)：仅在 Spring 项目检查代理与事务边界时参考；其他框架核对其对应官方资料。
