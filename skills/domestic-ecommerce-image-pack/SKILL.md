# 国内电商套图

## 目标

把用户上传的商品图转成有销售力的中文电商视觉，而不是只换背景或重复摆拍。适用于服装、鞋包、食品、美妆、家居、数码、玩具、工具、日用和其他实体商品。

每张图必须同时回答：给谁看、这张图卖什么、为什么可信、用户下一秒能看见什么。每张图只承担一个主卖点。

## 输入与事实边界

1. 将用户商品图、包装图、细节图和品牌素材作为最高优先级身份锚点。
2. 先提取可见事实：外观、颜色、结构、材质观感、纹理、配件、包装、可读文字、使用方式。
3. 将卖点分为 `Confirmed`（用户明确提供或图片可见）、`Needs proof`（需要参数/证据）和 `Unavailable`（不可推断）。只把 `Confirmed` 写成图内主张。
4. 不擅自改变商品颜色、形状、Logo、结构、数量、接口、包装或关键比例。不虚构成分、参数、认证、销量、功效、对比、评价、发货或售后。
5. 参考图不足以确认全貌时，优先做局部工艺、场景氛围或已知视角图；对完整正面、背面、尺寸和使用步骤保留“待补图/待补资料”标记，不强行猜测。

## 先做 4 张快速试样

用户未要求完整套图时，默认生成 4 张测试图，先确认商品还原、卖点方向和文案风格。按商品已知信息选择下列四种职责，不要机械套用品类模板：

1. **视觉钩子主图**：最强可见卖点 + 高对比场景 + 3～6 字主标题。商品必须大、清晰、第一眼可辨。
2. **证据卖点图**：放大材料、结构、工艺、包装或关键部位，以“看得见的细节”建立可信度。
3. **使用/搭配场景图**：把商品放进目标用户的真实使用场景；展示使用结果或搭配效果，不覆盖主体。
4. **风格收口图**：用不同于前 3 张的视觉构图强化质感、送礼感、收纳感、品牌感或购买理由。

完成试样后，说明每张图的投放/详情页位置、主卖点、使用的事实来源和需人工复核项。用户确认风格后，再扩展为 6～10 张完整套图。

## 画面与文案规则

1. 每张图都指定：背景/场景、主体位置、视觉焦点、主标题、副标题、色彩方向和留白位置。
2. 使用短、具体、可扫读的中文。默认主标题 3～6 字，副标题 6～14 字；标题聚焦一个已证实卖点。
3. 把文字作为设计元素，而非事后补充：指定位置、颜色、字号层级和不遮挡商品的安全区。
4. 生成含中文文字的图片后，逐张核对错字、漏字、变形字和错误数字。文字不可靠时，重生成一次；仍不可靠则输出无文字主视觉和精确的后期叠字稿。
5. 背景必须服务卖点：
   - 材质/工艺：微距工作台、同色纹理、定向侧光。
   - 使用效果：真实生活/工作/通勤环境，主体仍清晰。
   - 高级感：干净棚拍、克制道具、色彩统一。
   - 性价比/功能：明亮干净、结构化留白，避免伪造数据图表。
6. 避免同一背景、同一机位、同一文案句式连续出现。4 张试样至少包含 3 种构图或场景。

## 图像生成执行

1. 对每张资产单独生成；不要把不同定位的套图合并为一个批量提示。
2. 每个提示都标明：资产定位、参考图角色、商品不变量、场景、构图、灯光、中文原文、文字位置和禁止项。
3. 先使用高信息密度的主视觉；不生成无文案、无场景、无卖点的“空白商品图”，除非用户明确要求白底图。
4. 若一次生成失败，单张重试，不影响其余图片；不要因网络错误重复已经成功的资产。
5. 生成后检查商品身份连续性、文字、手/人体、边缘、透视、背景逻辑和事实主张。发现硬伤时只针对该图重做。

## 默认输出卡

先给出：

- 平台与画幅（用户未指定时用淘宝/天猫移动端：主图 1:1，详情图 3:4）
- 已确认商品事实与可用卖点
- 4 张试样的定位、标题和背景方向
- `Assumptions / Defaults Used`

生成后，逐张列出：文件/图片序号、页面位置、标题与副标题、主卖点、事实依据、人工复核项。不要声称没有生成的图已经完成。

## 调用示例

```text
使用 $domestic-ecommerce-image-pack，根据我上传的商品图生成 4 张淘宝详情页试样。
每张都要有不同背景、一个可证实卖点和短中文文案；先保持商品外观和品牌元素真实。
```
