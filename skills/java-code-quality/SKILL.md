# Java 代码质量

## 先识别项目

读取当前任务范围、工作区规则、构建文件、格式与静态检查配置，再抽查相邻生产代码和测试。确认 JDK 版本、Maven/Gradle 或其他构建入口、生成代码边界、公开 API 兼容要求。采用仓库实际提供的 wrapper 和命令，按当前操作系统选择入口；不要假设工具已安装。

用户明确要求优先，其次遵守项目既有约定；本技能的默认风格仅填补空白。冲突影响公共接口或大量文件时先说明具体差异，不擅自全库格式化或迁移框架。根目录的 Maven 聚合工程本身合理，是否放在子目录取决于仓库组织，不能照搬某个产品的布局。

## 写代码时落实

- 无既有格式约定时，使用四空格普通与续行缩进，合理行宽；类、方法、成员变量的声明注解各占一行。**方法参数注解与参数保持同行，只在整行过长时按参数边界换行。** 类型使用注解、局部变量注解和 record 组件应按语法角色处理，不要套用字段声明规则。
- `if/else/for/while/do` 的控制体使用花括号；单表达式 lambda 可以保持表达式形式。方法与 XML 元素不要挤成单行；链式调用和嵌套 lambda 格式化后抽查缩进，必要时提取有业务含义的局部变量或方法。
- 按职责或业务模块组织代码。协议适配、业务规则、数据访问、配置与启动代码应能分别定位；沿用现有架构，不为短小库强建 Controller/Service/Mapper，也不制造只有转发作用的接口层。
- 已知字段的请求、响应和操作结果使用明确类型；按 JDK 与框架兼容性选择 class/record。Map 适合真实动态字典，不用它规避契约定义。明确可空、单位、金额精度及集合可变性，避免直接泄漏持久化对象中的内部字段。
- 使用 try-with-resources 等适用机制关闭资源；不吞异常，不记录密钥或完整敏感请求；线程共享对象与可变静态状态检查生命周期和竞争风险。注释解释边界、约束和原因，语言、作者与时间标签沿用团队约定，不注入个人身份或虚构时间。
- 数据访问沿用现有技术。简单 CRUD 可复用框架能力；复杂查询、锁和原子条件更新归入清晰可审查的数据访问单元。采用 MyBatis 时可放 mapper XML；其他框架使用其查询模块，不强制 SQL XML 化。参数绑定替代输入拼接，重构时保留归属条件、事务和并发语义。
- 配置格式沿用项目统一约定，不能把 wrapper 的 properties 元数据误当应用配置转换。构建 XML 保持正常缩进与元素换行，不因格式化改变依赖解析语义。

参数示例：

```java
@Override
public Result find(@NotNull String id, @Nullable String locale) {
    return repository.find(id, locale);
}
```

## 验证与反馈闭环

1. 优先运行已有 formatter 的范围限定或检查模式，再查看差异。若工具不能安全限定本次修改范围，手工对齐新增代码并运行检查，不执行全库 apply；不触及生成文件或无关代码。新增 formatter/Checkstyle/PMD 等工具时核对 JDK 支持并固定兼容版本；不要用正则声称解析了完整 Java 语法。
2. 配置注解规则时区分字段、声明和参数 token；用短参数、长参数、字段注解、类型注解的合规样例和应拒绝样例证明规则不过度限制。IDE 与 CI 使用同一规则来源，不同格式引擎不承诺逐字相同。
3. 编译受影响模块并运行行为测试。重构重点验证公开契约、错误路径、资源释放、隔离与并发；格式变更使用编译/静态检查，不堆叠只复述实现的测试。
4. 对每个发现说明位置、实际影响、证据和修复方案；区分缺陷与风格建议。修复本次范围内问题后重跑相关检查并复查，不能以大范围 suppress 或放宽断言掩盖失败。
5. 报告采用的项目规则、已修复项、执行命令与结果、未验证项。格式通过不代表架构或业务正确；缺少环境时准确记录阻塞，不宣称完整适配。

## 官方依据

按项目版本核对资料；这些来源不要求安装指定插件，也不代表本技能覆盖手册全部规则。

- [Alibaba P3C](https://github.com/alibaba/p3c)：Java 工程实践与开发手册参考；团队已有其他规范时保持一致。
- [Checkstyle AnnotationLocation](https://checkstyle.org/checks/annotation/annotationlocation.html)：声明注解检查范围及配置限制，不能把规则名误读为所有注解都必须换行。
- [Checkstyle NeedBraces](https://checkstyle.org/checks/blocks/needbraces.html)：控制体检查及可配置语法范围。
