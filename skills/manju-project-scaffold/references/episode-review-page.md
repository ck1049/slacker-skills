# 每集实时制作审阅页

每集维护一个稳定入口，默认 `制作审阅/本集制作总览.html`，数据来自同目录 `素材清单.json`。已有项目可沿用自己的稳定路径，不另建一串互相失效的“最新页”。跨集批次另做汇总链接，每集仍有明确入口。此约定适用于用户选择的制作平台，不改变模型、费用或生成授权。

## 内容与布局

- 页首显示作品/集名、当前阶段、最近更新时间和实际任务状态。生成进度与采用状态分开，代表性小样不能充当整集完成率；无完整计划时不编造百分比。
- 默认面向用户展示**最新完整审阅候选和未解决事项**，清单使用 `review_mode: "complete"`。片段齐全后，在已授权范围内主动完成选段、排序、字幕、标识及必要配乐，导出成功即替换同一入口的当前整集；不要停在下载完成、只列片段或等待用户催剪。仍缺关键镜头、导出失败或新版处理中时显示实际进度，不让旧成片占据当前播放器。
- 用户明确审查素材时使用 `review_mode: "materials"`，按需展示**剧本、图片素材、音频素材、视频片段、音效、音乐、成片**。未生成的事项放进任务进度，不伪造可播放卡片。素材台账保留完整记录；整集审阅不要求用户逐段拼出故事。
- “默认先看成片”不等于隐藏制作来源。在当前成片下方保留可展开的**本版采用素材与时间线**：依实际合成回执列每段顺序、成片时码、源片区间、原生/超分源片、实际绑定参考图和生成时音色锚点，全部输入按实际绑定顺序展示，图片预览、音频和视频参考均可播放或打开；不能只取第一张图片。并提供字幕、实际配乐层、混音与回执。只列该版实际使用的来源，不把全批已下载或全局最新音色当作本版采用；退回或未使用候选仍留历史。原声静音、裁切、调色等处理照实说明，源片播放器可能含未采用头尾须明示。来源可查不要求用户逐段审片。
- 剧本直接可读并可打开源文件；图片用本地预览、可打开原图；音视频提供播放器、用途、版本、状态及必要说明。音色参考和完整对白分别标注；音乐标注母带/参考/采用段，成片标注候选或定版。
- 同一逻辑素材只展示明确选定的当前版本。整集模式只允许一个当前完整候选；不能按文件名或修改时间猜最新版。新版本可标“待审”，不能因生成成功标“已采用”。退回、废弃、替换或因选片改变而过期（`stale: true`）的版本不进入当前播放器。旧版保留在历史记录，只有用户明确要求比较时才做单独对照，不为“方便查阅”重新混入默认页面。
- 每个部分和每项素材提供“打开所在文件夹”、打开/下载原文件及“复制文件夹路径”入口。普通本地 HTML 不保证能唤起资源管理器；文件夹链接可能受浏览器限制，复制路径应能手动选取作为回退。不得为了按钮安装协议、开放远程目录或创建任意命令执行服务。

关联审阅页可通过 `related_pages` 数组显式声明，每项包含 `label` 与本地 HTML 文件 `path`；生成时校验文件存在并提供入口，避免参考审核页被遗漏。

### 视频候选与真实输入

素材模式的每个视频候选使用独立卡片，并在该卡的 `input_references` 中按任务实际绑定顺序记录每张图、每段音频、每段视频参考和配置记录：`kind: image/audio/video/record`、`path`、`label`、`role`、`sha256`。渲染器直接在该片播放器下生成可展开的图片预览、原文件链接及音色链接；未记录时明确提示缺失，不从全局索引或文件名猜测。用户要求原片与返修比较时使用不同卡片和实际任务身份，待审不等于采用。图片来源、版本、眼部等局部身份锚点和创作者给的截图用途须与用户指示一致；构图板、三视图板只供人工审阅时不要当作视频模型单张人物图。

每次生成/收片/换参考/返修后同步清单与稳定页面，核验每个播放器与对应输入链接均指向存在的实际文件，并检查角色基准、生成参考、场景和用户参考可见；缺字段明确待补，不用临时页面注入代替通用模板。用户要求先审参考图时，必须在当前入口或可直达的参考审核页展示所有本批待审角色、场景、动作和关键道具，并标明版本、来源、待审/通过/淘汰；用户明确满意后才用该批准范围生成视频。声音试听、图片审核和视频连续视听分别记录。

## 清单与增量更新

`scripts/scaffold_manju.py` 创建目录时初始化清单和空页，已有文件不覆盖。使用 [HTML模板](../assets/episode-review.html) 和 `scripts/render_episode_review.py` 渲染。脚手架重复执行不能改写用户的清单、页面或当前选片。

清单示意（路径相对于清单所在目录，下面是字段示例，不是已存在的素材）：

```json
{
  "title": "作品名 · 第06集",
  "summary": "素材制作中，整集尚未完成",
  "review_mode": "materials",
  "updated_at": "2026-10-24T20:00:00+08:00",
  "tasks": [{"name": "镜头03返修", "status": "生成中", "note": "等待同一任务，不重复提交"}],
  "items": [
    {"id": "角色A军训造型", "category": "images", "version": "v001", "current": false, "status": "已退回", "path": "../角色/造型_v001.png"},
    {"id": "角色A军训造型", "category": "images", "version": "v002", "current": true, "status": "待审", "path": "../角色/造型_v002.png", "preview": "预览/造型_v002.jpg", "note": "替换旧造型；动态表现未验证"}
  ]
}
```

类别值：`script`、`images`、`audio`、`video`、`sfx`、`music`、`final`。每项需要 `id/category/version/current/status/path`；`label/note/preview/stale` 可选。`review_mode` 省略时为 `complete`；材料模式须显式写 `materials`。状态由实际制作记录填写，`stale` 如出现须为布尔值。`current` 是展示选择，不是最终采用授权；同一类别同一逻辑 ID 不能有两个当前版本。渲染器拒绝重复当前选择，不按修改时间或文件名猜最新版。含有`已退回/已废弃/已替换`的状态或 `stale: true` 不渲染成媒体卡片；有候选可明确选候选，无候选保留任务状态。

1. 剧本修改、素材落盘、审阅退回、版本替换、任务状态变化、剪辑导出或定版登记后，更新受影响清单并刷新 HTML；每段下载后即可更新，不等全批结束。
2. 以素材逻辑 ID、来源路径及项目记录的指纹维护选择；页面引用真实文件和实际任务状态，不从整个磁盘盲扫同名素材。每个整集保存来源镜头、源SHA、采用帧区间、顺序与合成回执；选片或返修变化影响整集时标记旧整集过期，重新对齐字幕、混音和导出。新版本使用新文件，更新清单当前指向；隐藏旧版不等于删除源片或证据。
3. 将到片→判断本集是否就绪→本地剪辑/导出→更新清单→渲染的调用接入实际流程；分别按集触发，已就绪的一集不必等待另一集无关任务。若已有候选待选段，先处理后期，不为清空任务状态盲目重生成。只有脚本存在不代表事件已经接入；确认后台正常运行、每个阶段结果及失败记录。已有自定义HTML应调整其生成器，不能手改一次后又被旧生成器覆盖。渲染器本身仍只读清单和素材、写页面，不启动生成、上传或修改采用授权。
4. HTML 临时文件写完后原子替换；渲染失败保留旧页，记录失败，不声称已经刷新。文件缺失、清单冲突须修正实际引用，不用旧废稿静默补位。
5. 自动刷新默认关闭；旧页面曾保存的默认开启状态不能自动继承。用户主动勾选后才每15秒刷新，播放、页面不可见或正在复制路径时仍暂停刷新。手动刷新始终可用，尽量保留滚动位置。后台更新HTML与浏览器重新载入是两件事：制作程序继续写最新文件，不因此强制打断用户正在看的视频；刷新不查询云队列或启动模型。

### 整集采用清单字段

整集清单可提供 `adoption`：`version`、`final_sha256` 必须匹配当前成片记录；`fps` 声明时间码换算帧率。`clips` 按实际剪辑顺序列出 `id`、`source_frame_range`、`timeline_frame_range`（均为含起帧、不含结束帧）、`source_video`，并按实际提供 `native_video`、`input_references`、`voices`、`records` 与说明 `note`。每个来源包含本地 `path` 和已有指纹；`assets` 提供剧本、字幕、音乐、音轨、合成回执等，类别为 `script/subtitles/music/audio/record`。生成器从导出回执和其任务绑定构建此字段，不从下载目录猜测采用。版本/指纹冲突或来源缺失时保留旧页并报错，不能静默补旧素材。

## 流量、交付与检查

图片懒加载，音视频 `preload="none"`、不自动播放；不用大体积 Base64 嵌入，不因页面刷新重复上传原图。资源路径优先相对路径，跨盘资源可用本地文件链接。复制单个 HTML 不会附带素材；需要分享时发送对应原文件，或在用户要求时导出含所选资源及相对链接的便携包，不自动上传或发布。

验证覆盖旧版退回→新版待审、新选片使旧整集过期→导出后更新播放器：默认只播新整集，材料模式可单独检查新素材，历史证据仍在；播放器实际路径和文件指纹匹配回执；源文件/文件夹链接、中文路径可用。另验自动刷新初始关闭、忽略旧默认开启记录、主动启用后播放期间不刷新、渲染失败保留旧页。技术核验、画面观察、连续视听和用户认可分别记录；待审候选中的动作、音色、角色表演等未验项照实列出。

### 完整绑定与兼容

`adoption.clips[].input_references` 与素材卡使用相同字段，必须从该源片的实际配置/提交回执逐项记录图片、音频、视频和记录文件（含绑定序号、用途、SHA）；不把全局当前素材冒充历史实际输入。未用视频参考就不添加占位项。旧 `reference` 单项只作兼容展示，须明确完整绑定尚未补齐。音视频均 `preload="none"`，不自动播放。验证至少涵盖同镜多图、音频、视频参考以及缺失文件导致原子渲染保留旧页。
