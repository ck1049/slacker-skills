# Seedance 2.0 Production Rules

Use these constraints for 即梦 Seedance 2.0 storyboard prompts.

## Platform Limits

- Single output video: 4-15 seconds.
- Reference material count: max 12 files.
- Reference types: video, image, audio.
- Single reference video: up to 15 seconds.
- Multiple video + audio references: combined duration <= 15 seconds.

## Prompt Requirements

Each clip prompt must include:

- Duration and aspect ratio.
- Visual style.
- Specific setting.
- Characters and appearance anchors.
- Facial expression and body action.
- Lighting and atmosphere.
- Camera shot size, angle, and movement.
- Sound direction.
- Reference material usage with clear labels.

## Clip Design

- Prefer one dramatic action or one emotional turn per clip.
- Use 8-12 second clips for dense story beats.
- Use 4-6 second clips for UI flashes, reaction shots, countdowns, and transitions.
- If a scene needs continuity, generate a storyboard still first and use it as image reference.
- Avoid asking one clip to cover too many locations or time jumps.

## Continuity

- Use global character cards for face, clothing, silhouette, and color anchors.
- Reuse scene cards for recurring layouts.
- Track altered states: injured, bloodstained, exhausted, transformed, powered-up.
- In each prompt, state whether the character is in default state or a specific episode state.

## Dark Fantasy Survival Tone

For death-game stories, emphasize:

- oppressive scale,
- rule-system UI,
- fog, cold light, blood-red warnings,
- sudden moral collapse,
- physical exhaustion and panic,
- contrast between silent calculation and crowd chaos.

Do not over-explain rules in narration when a visual UI or crowd reaction can carry the information.
