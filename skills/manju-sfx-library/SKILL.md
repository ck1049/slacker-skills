# 漫剧公共音效

本技能包含通用规范、检索/入库/导出/分轨脚本和离线测试，不携带音频、模型、账号或某台电脑的路径。Python 3.11+；转换与渲染需要本地 FFmpeg。保持自动选择，在已获授权的剪辑/音效任务内使用。

## 首次使用

读取 [配置与迁移](references/configuration.md)，运行 `scripts/sfx.py doctor`。音效库与 FFmpeg 按参数、环境变量或本机 JSON 配置解析。缺失时报告具体项目；不能把脚本目录当成音效库，不能自动安装依赖、下载音频或模型。

已有库优先复用；新库用显式 `--library` 执行 `init`，仅创建空清单。现有 schema v1 素材 ID、SHA 和项目方案继续有效。

## 日常剪辑

1. 读实际采用画面、对白、原音与项目约定，列开门、落脚、道具、环境或喜剧提示事件。确认原片有没有同类声音，避免重复叠加。
2. 用 `scripts/sfx.py search "中文或英文关键词"` 检索，按材质、距离、动作、时长和风格选候选。文件名/标签只是线索，采用前结合镜头试听。
3. 用 `export <ID> --out <新版本.wav>` 或 `render <方案.json> --out <分轨.wav>` 生成项目文件。参数和格式见 [素材与时间轴规范](references/schemas.md)。工具核对音频、许可证据 SHA，禁止覆盖，随结果保存来源与许可正文。
4. 将分轨接入现有整集混音，对白处适当让位，留意尾音、笑点停顿与声画同步。只改声音时沿用已确认画面，不重新生成视频。
5. 保存项目方案、采用来源、混音回执和试听结论；更新受影响的当前成片指针及制作记录，保留历史版本。

## 扩库与自定义

读取 [入库与权利规则](references/library-workflow.md)。优先现有 CC0，其次查证新的 CC0；其他许可单独评估，不混标。`scripts/import_assets.py` 接收已取得的音频和已审核的许可/自有权利声明，之后用 `build_catalog.py` 生成剪辑副本和浏览目录。

自录文件可按 `source_kind=self_recorded` 和 `LicenseRef-Self-Owned` 入库，保留录音者、时间与权利说明；这只记录拥有者的使用依据，不把声音公开奉献为 CC0。单纯增加符合现有格式的自录素材不需要升级技能。新增录音采集、降噪、切分、设备校准等能力时，再添加相应参考流程/脚本并验证；本版不控制麦克风、不执行这些处理。

## 持续遵守

- 技术可解码、许可已核对、素材听审、整集连续听审分别记录；未试听如实标为 unreviewed。不得以峰值限制或脚本成功替代听审。
- 通用素材留在独立库；角色声线、对白与项目专用派生文件留在项目内，不因共用工具就跨项目复用。
- 普通本地调用沿用已获授权的任务范围。付费、上传、模型下载与暂停任务恢复需要相应授权，技能自动触发不扩大授权。
- 既有源文件、许可证据和 SHA 未变可复用记录；改文件应新版本入库，不直接覆盖旧音频。
- 开源工具许可不等于输入素材或生成结果许可。来源不明、非商用素材和未经授权的影视截取不进入商业候选。
