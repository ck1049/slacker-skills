# 入库、权利与剪辑规则

## 选择与权利

优先级为本地已核验 CC0 → 作者/官方站点 CC0 → 有明确许可的其他免费商用资源 → 自录/参数合成 → 确有需要再评估 AI。名称写“免费”或“无版权”不是许可证明。

- CC0：保存作者来源、许可版本与正文/页面快照，逐条绑定音频 SHA；同包可共享许可。
- 自录：确认录音者及实际权利拥有者，检查录入的他人语音、背景音乐和第三方声音。保存权利说明；默认不公开、不开源、不自动改为 CC0。
- CC BY：需要落实署名；当前脚本不准入，先准备相应许可处理流程，不得改标签绕过。
- CC BY-NC、来源不明、未获授权的影视/游戏截取：不进入商业候选。
- Mixkit、Pixabay 等平台使用各自许可，核对商用、修改、单独再分发和项目源文件交付条件；不能标成 CC0。当前脚本只处理 CC0 与已确认的自有录音，其余另行扩展后再用。
- 自录的 `LicenseRef-Self-Owned` 是本库内部权利依据标识，不是面向第三方的通用授权书；允许使用不意味着允许公开散发素材包。

新增来源实时读取对应条目的许可，记录审核人/执行者与时间。机器检查只能检查记录完整和证据未变，不能独立证明版权归属。已有证据和源文件 SHA 未变可复用；不用每次剪辑重访原站。

只获取当前缺口需要的小批量素材，保留原文件；不扫站，不绕过登录或访问限制。付费、上传和模型下载依照用户与宿主项目授权，不自动进行。

## 入库流程

1. 将本地音频、许可/自有权利说明放在待入库目录，按 schemas.md 写 manifest。`license_verified=true` 必须来自实际阅读与核对，不能为了通过程序而填写。
2. `import_assets.py` 校验整个 manifest，复制原始音频与 UTF-8 权利文档、保存指纹和来源回执；不会下载，也不会删除原文件。同 batch_id 与同 manifest 重跑只核验，不重复导入。
3. `build_catalog.py` 从全部已核验回执生成 48 kHz 双声道 PCM16 剪辑副本、catalog.json、CSV 和离线音效库.html。不强制归一化，不裁切源文件。重采样不能恢复有损质量。
4. 按真实听感补充标签与试听结论。默认中文标签是文件名推断或入库人描述，不是自动听审。保留原始记录；听审记录随输出 SHA 绑定。
5. `sfx.py verify` 核验索引中的音频和来源回执证据。重建若会丢弃原有条目将拒绝执行；先恢复缺失回执，不静默缩库。

目录：`原始素材/`、`剪辑素材/`、`来源与许可/`、可选 `下载包/`；清单与试听页在库根。项目采用方案、导出音频和混音回执保存在项目。用户本机运行配置位于库外或独立的 *.local.json 文件。

## 自录何时更新技能

- 只是新增录音：依现有 manifest 填写录音者、时间、权利说明、名称、分类、关键词并入库，不改技能。
- 更换麦克风、地点或录音参数：写进该批 recording_metadata，不把设备型号变成所有项目必须遵守的规则。
- 新增采集、降噪、自动切分、响度处理、循环点制作等可复用流程：增加对应参考规范/脚本，并验证保留原始音频、处理参数与派生 SHA 后，更新技能版本。
- 不同来源的加工结果都应记录输入 SHA、工具版本、处理参数、输出 SHA 和试听状态。现有录音与旧处理结果不能被新流程覆盖。

## 成片接入

从当前实际采用剪辑定位事件，检查已有音效避免重复。脚步按真实落脚安排并轮换变体；没有足够信息就标明待定位，不从视频生成提示词编造时间。

分轨只含音效；合入对白、原声、配乐时控制整体电平，对白处适当让位，关键停顿可留白。监听同步、材质、距离、尾音、突兀感和遮蔽。技术检查、单条试听、整集连续听审分别记录。

只改音频时可沿用视频流；若同轮需要重烧字幕/水印，按项目既有合成流程执行。保留旧成片，更新真实最新的文件指针、来源清单、合成回执和审阅页面。
