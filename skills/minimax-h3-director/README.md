# MiniMax H3 Director Skill — V1.0

An evidence-aware skill for turning briefs, stories, scripts, and reference plans into MiniMax H3 video prompts and shot plans.

Start with `SKILL.md`. Read `OFFICIAL_SOURCES.md` for provenance, `templates/` for forms, and `tests/cases/` for smoke cases.

This package deliberately does not treat the six-part layout, English-only prompting, fixed order, fixed word count, or Subject/Picture/Video/Audio labels as hard requirements without a direct official citation.
