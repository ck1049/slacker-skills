# Update process

1. Weekly or release-triggered check of the official URLs in `OFFICIAL_SOURCES.md`.
2. Record only material changes with date, URL, claim, evidence class, and impact.
3. Re-run the regression cases and add a case for every newly observed failure mode.
4. Promote a community or experiment rule only after evidence is attached and its status remains labeled.
5. Bump patch for wording/tests, minor for new workflow support, and major for changed output contract.
6. Human-generate representative videos before calling a behavioral change validated.
