# Evidence policy

Use four labels in notes and case records:

1. `official_explicit` — directly stated by a current MiniMax-owned document.
2. `official_example_inference` — pattern inferred from an official example; useful, not binding.
3. `community_experience` — article, forum, or creator report; preserve provenance and uncertainty.
4. `project_experiment` — reproducible result from this project, with prompt, model, settings, and evaluation.

For the supplied WeChat article, use `community_experience` only. The PDF was not available in the current workspace at V1.0 build time, so no page-level claim is asserted here. When supplied, extract claims into `references/community-wechat-article.md` and verify each against the official register.
