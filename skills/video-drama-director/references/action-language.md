# 从能力、结构与意图设计动作

适用兵器、徒手、法术、群体、异形与载具动作。这里提供电影创作的推导方式，不是现实搏击/武器操作教程。只挑当前角色和场面需要的维度；名称清单不能代替编排。

## 1. 按属性推导，允许混合与例外

先看角色/器械的真实参考或作品设定，再确定：

| 维度 | 导演要回答什么 | 可观察的表达 |
|---|---|---|
| 结构与驱动 | 刚性/柔性、长短、单件/多件；由手、身体、意念还是载具带动？ | 哪一部分先动，何处握持/连接，传导与回收的顺序 |
| 质量与时间 | 力量集中何处，转向/蓄力/回收需要什么条件？ | 轻快变线、沉重延迟、弹性回摆、周期启动；幻想例外也有规则 |
| 轨迹与作用 | 点、线、面、环绕、区域或持续场？靠接触、投射、束缚、护持还是改变空间？ | 清晰轮廓、作用范围与目标，不只特效颜色 |
| 身体与地形 | 人形/多足/飞行/巨型/载具；支撑、朝向、高差和障碍怎样改变运动？ | 手脚/翼/轮的先后、落点、转弯半径与环境尺度 |
| 时间和资源限制 | 次数、蓄力、持续注意、体能、损伤、弹药/法力或道具是否有限？ | 使用后有可见变化，受限时打法改变，不每镜满状态 |
| 人格与目的 | 是压制、护送、拖延、夺物、脱困、试探还是杀意克制？ | 同种器械也可有不同节奏、姿态、取舍与冒险程度 |

为当前角色写一小段动作语言：**结构/力量依据 + 常用轨迹与节奏 + 两三种可变的连接方式 + 局限/代价 + 性格表现**。先说明“为何这样动”，再选招式名；陌生器械结构或具体流派事实需要查证，不把影视惯例写成历史事实。

## 2. 动作家族是推导起点，不是封闭武器目录

下表仅供选择和变体，不要求全部出现，也不把材质、重量、锋利或灵活性永久绑定某个名称。虚构兵器按设定重新组合属性。

| 动作家族及可见对象例 | 可发展出的运动/场面差异 | 常见失败 |
|---|---|---|
| 刃器：剑、刀、双刃等 | 线条长短、单刃/双刃、握持与刃口决定斜掠、弧线、导偏或连续换面；同为剑可轻灵也可沉重 | 换名称仍是同一次正面挥击；用光效遮掉刃口朝向 |
| 长杆：枪、戟、棍等 | 长度、端部形状与重心决定点线/宽弧、伸展回收、两端参与及空间需求 | 当短剑原地挥；枪、棍、戟都只刺一下后停住 |
| 重型：锤、斧、巨刃等 | 蓄势、整体重心迁移、落点和回收代价形成分量；特殊力量可改变惯性但须事先设定 | 仅把武器放大；落击像轻敲，急停急转无解释 |
| 柔性/牵连：鞭、链、绳、飘带等 | 驱动端、滞后弧线、张力、缠绕与松脱；可与障碍形成持续空间关系 | 把绳当硬棍；无端点/无张力自行盘绕；跨镜长度和连接变化 |
| 双持/攻防组合：双刀、盾与短器械等 | 两手/两件器物职责不同，遮挡、护持、开路与接续形成节拍；负担与空档可被观察 | 左右手镜像重复；盾牌只是装饰；手里物件互换或凭空增加 |
| 远程/投射：弓弩、投掷物、影视枪械等 | 取得目标、释放、飞行/击中、后续状态构成不同节奏；遮挡和距离改变画面与声音 | 只拍发射光点；射出物凭空换向、重复命中、资源无故复位 |
| 徒手/身体 | 支撑、移重、闪让、接触和失衡形成重量；拳脚、翻越、抓握与脱困按人物目的组合 | 摆动作却无重心变化；对手被动配合；每次碰到都飞同样距离 |
| 法器/术法/领域/召唤 | 承载物、施术者、目标、作用空间和控制关系分别设计；可驱动、束缚、防护、改变路径或场地 | 全部变成站桩光束；法阵只是背景圆；召唤物无指令和作用 |
| 非人形/巨型/异形 | 体型、关节、足翼尾、感知及力量规则改变起步、转向、触地和对抗尺度 | 给巨兽套人类拳脚；只靠低机位和吼叫表示大，接触后地面无响应 |
| 载具/骑乘/环境动作 | 角色意图与载体运动分层；速度、障碍、震动、惯性和人/物相对位置互相影响 | 背景平移但人物不受运动影响；转弯、跨越和落地之间断裂 |

这些属性可混合：链刃有柔性段和刚性端，飞剑同时有器物身份与遥控规则，受损机甲有非人形结构和资源限制。未知对象也先填属性，不因不在表里就退回普通互砍。角色没有武器时不必凭空添武器来制造观赏性。

## 3. 招式由任务产生，再做变化与兑现

围绕本段主要转折，提出少量**机制不同**的动作方案，例如改走位层次、改变作用方式、利用环境或牺牲某项优势；选择最体现角色和剧情、且能清楚拍出的方案。不要只在同一动作上换武器/颜色/招式名，也不输出无意义的长词库。

需要建立个人招牌或较长段落复现时，可设计一个动作母题，让观众认出其轮廓、节奏或声音；按剧情选择首次建立、变形、被识破后调整等变化，一次性短动作不必强加复现。复现必须有新意义，不能把同一段素材反复使用来充当招式。胜负从先前埋下的规则、选择或代价中兑现，不能只因最后一招特效更大。

招式短卡按需要写：**目的 → 驱动/准备 → 轨迹与姿态变化 → 对手回应 → 接触或作用 → 新状态/代价 → 下一动作入口**。招式名可作为内部标签，最终文本仍须说清动作。以身体和受力组织关键姿态、加速与回收；适当有预备和余势，但不把每招拆成一套停顿展示。

表演随战局改变：疲劳影响呼吸和回收，受伤影响支撑或握持，恐惧改变出手选择，保护他人限制追击路线。只跟踪剧情相关的伤疲和资源，不强制游戏式数值、伤害等级或每人必受伤。

## 4. 多人战斗与非对称任务

先分配各方当前目标、位置、对谁施压、正在做什么、何时能改变主行动，再决定画面注意力。敌我不必数量或能力对称；护送者、施术者、追击者、撤离者、受困者都可形成不同任务。

关键时刻错峰发生，背景角色仍执行阻拦、绕行、协助、躲避、救援或准备中的任务；因障碍、同伴占位、判断或资源受限而暂未出手时，应在画面中成立。既不要所有人同时占据中心，也不要围成圈排队挨打。群体压力可通过前景追击、画外逼近声和后景路径变化维持，但关键行动不能永远藏在画外。

用战场局部与全局镜头交替保持方向可读。镜头切去另一人时，原动作在共同时间内继续或留下结果；不让全场等被拍的人动作做完。记清目标物、保护对象、不同阵营、异形肢体与召唤物身份，避免只能靠服装颜色猜关系。

## 5. 整场有起伏，声画一起选招

整场按任务变化组织试探/追逐、压力累积、反制、代价、转折和结果，按片长与题材取用；不是每场必套六段。速度、远近、高低、攻防、安静/爆发交替服务故事，不靠招式越来越多或爆炸越来越大获得升级。

重要招式在设计时就确定：观众先辨认什么、摄影如何展示完整路径、哪种特效表达作用、关键声音何时突出、余势如何进入下一镜。按 [特效与声音](effects-and-action-sound.md) 编排后再压缩执行提示词。遇到模型难点可拆镜、绑定动作参考或后期处理，不能删除这场最有辨识度的机制却仍宣称完成。
