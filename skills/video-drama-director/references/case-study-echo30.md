# 《回声提前三十分钟》案例：技术完成后的创作失败

2026-10-01本地审计360镜、33:05.333的实际提交图与选片；用户完整审片指出单调、机械表演和因果/状态问题。以下为项目证据，不宣称所有模型都有这些缺点。核心不是“模型不够强”，而是稳定性模板把戏删掉，技术检查又没有衡量戏。

| 本次证据 | 后续决策 |
|---|---|
| 276/360实际提示词要求固定距离/机位与克制动作；计划多人只有9镜；0镜含第二分镜标签 | 身份锁与机位锁分开；先设计空间互动和镜头组，不按一句台词生成一张正面照 |
| 261/360套相同清晰干声，278镜固定音色；272镜重复雨声/电气嗡鸣描述 | 声音身份与当场表演分开；情绪意图、语速/停顿/呼吸与声床对比需另写、另听 |
| 103镜用编辑版，74个文件名含close；351/353将放插头/推设备改画外近景 | 文件名只是诊断；裁掉关键动作须补镜或修改后续依赖，不当作戏剧通过 |
| 43夹子被要求先向桌边滑动且无人手入画；44仅规定落地余振 | 补施力/失去支撑的原因，运动—声音—停止有对应；余振不能解释永动 |
| 未插接耳机仍响是大纲有意异常和开放结尾 | 不全归bug，但异常须有断开证据、声源规则、验证/反应与兑现 |
| 257/295/330/333复用同一右上角指针起态图；305归零，330意图切另一水位表但外观/机位相同 | 继承实际末态，解释复位；两种仪表用可辨识物理身份而非只改名字 |
| 333动作抽样量测与301等关键帧方案确有改善 | 保留关键帧/动作检查，并延伸到跨镜状态；局部动作成功不证明整场有吸引力 |
| 全片解码/ASR/声纹/音频对齐通过，但没有全片人耳听感和完整动态验收 | 技术、创作设计、单镜实现、连续段落和用户认可分别报告 |
