# 已获用户认可的局部返修案例

仅在需要核对经验依据或迁移方法时阅读，不是普通创作的前置材料。这是两个已有制作闭环的匿名摘要：有真实输入、任务、输出与后续采用记录；私有原片、回执及精确配置不随公共技能分发，因此不是可公开逐帧复跑的模型基准，也不能据此统计技能提升了出片率。

## 案例一：持姿任务与主观反应分别返修

| 环节 | 已有证据与决定 |
|---|---|
| 需求与退回 | 群体训练须保持站位和可见手腿接触；用户认为原版总体尚可，但手型松散、人物随巡查走动、疲惫只拍主角、Q版表情过短且解释字卡多余 |
| 原失效 | 文本动作正确而参考接触结构不符；把短反应的试剪建议当固定秒数，一秒静图推近没有完成表情弧 |
| 导演与实际输入 | 分开现实持姿、前后排疲惫与主观反应。先修接触关键帧，实际绑定到对应新视频任务；沿用原项目模型/加速/采样与后期链路，没有把配置变化当成改善原因 |
| 实际返工 | 新持姿片观察中段与站位；首个疲惫候选张口过大被退回，下一版改为眼睑、汗迹与前后排移焦。Q版采用实际表情动画，保留完整反应弧并删除多余解释字 |
| 输出与剩余偏差 | 离散观察支持部分新手型、站位与表情变化；仍见轻微摄影推近，不能写成绝对锁机位。一个教学手型仅采用其可用尾段；实际取段、原对白与最终输出指纹均有记录 |
| 最终依据 | 用户随后认可该返修整版并要求登记正片，登记与实际交付文件指纹对应。用户认可不补写助手未完成的连续视听、听感或逐项无瑕疵证明 |

可迁移决策：持姿任务检查可见支撑与中间过程；主观夸张保留完整反应和恢复现实的状态；后期可用区间与整条源片分别评价。不同对象可用于乐器持握与后排注意力，但不能把全身静止或某个Q版时长强加给演奏者。方法见[表演与后期声音](expressive-comedy-and-post-sound.md)、[返工与选片](review-and-iteration.md)。

## 案例二：信息屏面先修实际输入，再局部替换

| 环节 | 已有证据与决定 |
|---|---|
| 需求与退回 | 成绩查询画面须让观众读懂字段、分值与合计；原实际画面存在伪字、重复字段和错误数值 |
| 原失效 | 草稿提示词中的数字虽正确，实际视频任务没有绑定准确界面参考；原阅读镜头也过短 |
| 导演与实际输入 | 按项目适用规则核对字段关系，先原生排字制作可编辑底板与屏幕关键帧并目视检查，再确认该版本进入实际视频任务；具体事实、地区年份和配置留在项目证据 |
| 实际返工 | 在独立预算批准后仅创建一条局部替换任务，没有重做其他对白；延长可读停留，后续字幕与姓名卡按新增长度整体校时，保留旧版本和原声音顺序 |
| 输出与技术边界 | 实际下载、输入绑定、完整解码、保留画面对照和输出指纹可追溯；这些技术记录不等同于完整连续视听或字形在每帧都稳定 |
| 最终依据 | 用户随后要求将该完整修订版登记为正片，当前采用指纹对应实际文件；未把登记理解为已经发布，也未推导所有模型均能稳定生成文字 |

可迁移决策：准确内容、实际绑定、动态可读时间及下游时序要连在一起。用于票券、账单、仪表或屏幕时，另查本项目适用事实和揭晓时点；装饰性虚构文字无需套现实计分制度。详见[信息道具](expressive-comedy-and-post-sound.md)和[状态与揭晓](continuity-and-sound.md)。

## 这两个案例能支持什么

它们支持“已有问题经具体制作修正后，存在获用户认可的版本”，并说明失败、局部改善与最终采用可被分开记录。它们没有控制全部变量，没有重复制作品质实验，也没有测量跨题材成功率。复用方法时重新检查当前输入和实际结果；不能把用户认可当模型保证，或为复现个案自动生成新媒体。
