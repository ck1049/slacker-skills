# 战斗动作、空间与摄影

用于武侠、仙侠、现代动作、科幻、追逐、救援和连续战斗。以下是导演设计与返工方法，不是格斗教学、历史定论或模型成功保证。安静对白、蓄势对峙和静止美学不必套用高速战斗要求。

按当前难点读取：设计兵器、徒手、异形/载具或群体动作时读 [动作语言推导](action-language.md)；涉及核心特效、能力或声音表现时读 [特效与声音编排](effects-and-action-sound.md)；需要跨题材写法时读 [多类型动作示例](action-examples.md)。先解决本场任务，不把三个参考中的所有选项都写进每个镜头。

## 1. 保住用户要看的力量与风格

把美术质感、力量等级、角色打法、段落节奏分开决定。真人写实可以表现超常力量；干净明亮可以有远距离气劲、空中换位、横贯水面的冲击和大幅运镜。场景完整不等于环境毫无反应，也不必每次爆发都炸成废墟。

将本场“高武”转成观众看得见的尺度与规则，按设定选择：交战距离与位移、垂直空间、力量如何传导、影响多大范围、对手如何应对、爆发的限制或代价。可以写跨过一段庭院、掠上回廊、枪劲沿池面掀开水脊；不用只在人物近身动作上加一条发光贴纸。力量不必处处最大，但核心段落须兑现所设等级。没有具体等级时给出可调整的假设，不默认为地面近身切磋。

列出本段不可丢失的创作目标，例如“枪势跨距离压制，剑法转线破势；有连贯追击；交战路线穿过池沿与阶台”。模型降载时保住这些目标。用户确认服装/光色参考，只说明美术获认可；一张漂亮剧照不能证明高速动作、力量尺度或动态摄影已经成立。

| 当前题材/约定 | 从什么产生观赏性 | 避免套错规则 |
|---|---|---|
| 现实尺度武侠/现代动作 | 身体与器械差异、时机、空间障碍、受力、人物选择和局势变化 | 不为“精彩”擅加气劲、踏空、爆炸或无限体力 |
| 高武 | 已设力量如何拓展运动、交战距离及环境响应，人物如何驾驭与反制 | 不能只添加光带；也不必每招拆楼毁城 |
| 仙侠/术法 | 各能力的作用规则、控制关系、施展变化、限制与交互，身体和场地参与 | 不把御物、阵法、变形、召唤、领域全编成光束对射 |
| 非人形/科幻/载具 | 身体结构、运动介质、技术或世界规则带来的独特行动与代价 | 不套人形挥砍，不把运动载体当静止房间 |

先问战斗在故事中解决什么：获胜、保护、拖延、夺物、脱困、试探或改变关系。按需要安排新信息、旧打法失效、取舍与结果；强度升级可来自代价和局势，不能只靠越打越亮。题材可混合，边界以本作品设定为准。

用户要求轻功、飞行、空中换向或远程攻击时，分别设计其作用与可见兑现：借力腾越与自由飞行不是同一能力，远程攻击也不能只打无人地面。写清起点、路径地标、距离/高度变化、目标、敌方应对及落点/持续飞行状态。腾空之后的封路、追击、变向仍有因果；不把高武降成小台阶上跳一下，也不以“空中动作较难”为由默默删掉核心体验。

远距交锋、巨大实体化招式或大范围术法是高武/仙侠的重要能力分支。按 [远程攻击与巨幅特效](remote-and-large-scale-effects.md) 建立传播、尺度、应对和损伤/消散；用户要看这些体验时，代表性测试必须覆盖，不用普通近身交锋替代验证。

## 2. 先设计参与者的动作语言

对每个参与者按相关属性写：意图、身体/器械结构、控制方式、作用形态、距离与覆盖、惯性/回收、资源或能力限制。由此推导轨迹、姿态、节奏、标志动作及可利用的局限。按 [动作语言推导](action-language.md) 从少量机制不同的动作方案中选择，避免只给武器名配形容词。招式名可辅助角色风格，必须同时写可见动作及对场面的影响。

下面保留一次剑枪复盘中的局部示例；它不是完整动作库，也不是默认场景。其他器械、徒手、法术、非人形和载具按属性推导，详见上述参考；用户设定优先。

| 对象 | 动作与视觉特征 | 如何参与攻防 | 应避免 |
|---|---|---|---|
| 单手直剑：轻灵、精准、锋利 | 侧身换线、剑尖带动短弧、刃口斜掠卸力；转腕与身步衔接，衣袖形成轻快余势 | 引偏枪线后切入空档，利用对方换向继续攻；剑气窄而有清晰路径，可远达，不能因“细”就无力 | 永远正面硬顶枪头；挥剑停住，再挥同一下；没有交锋目的的转圈炫技 |
| 长枪：长距离、大开大合、压迫 | 枪尖引领长线突进，腰身转动带出横扫；双手位置随收放调整，枪身长弧与衣袍形成大轮廓 | 以长线封位、扫势迫人换层，回收接续突进；近身时可变握距或用枪尾解围，须有合理空间 | 把长枪当短剑原地抡；轮轮自转等对方；将长枪写成只能笨重挥砍 |

锋利可通过掠过后被切开的落叶、绷断的绳或清晰剑气切线呈现；“杀伐/压迫”可通过封路、步步追进、对方被迫改变高度/路线呈现。不必依赖血腥。抓握、武器长度和运动轨迹在同一场里保持可辨识。

高武能力要延伸身体与兵器的动作语言，不能把所有交锋改成站在两端轮流发光波。按战术组织远距封路、身法接近、实体接触与再次拉开；不强制每场都出现所有距离，但不能靠气劲特效跳过用户要看的招式。

## 3. 用连续攻防链代替轮流展示

一个主要事件可以是“夺回池沿外线”，内部包含若干互相导致的动作：

**起势/在途压力 → 进攻路线 → 对手规避/格挡/截击 → 力量与空间后果 → 利用后果继续出招。**

每一环回答谁掌握主动、相关参与者正在做什么、为何下一动作必须发生。单人追逐或救援也要交代环境压力与回应。动作数量由可读性、表演与模型能力决定，不按每秒固定招数。给必要的伸展、回收和落脚留时间，同时让回收成为下一动作的准备；不要求无惯性瞬间变招。

多人场景给所有关键参与者分配共同时间下的任务与压力来源，错峰转移注意力。暂未介入要有受阻、保护、绕行或判断等原因，不排队等拍；护送、夺物和追逐的结果也算动作推进，不强制每个节拍都击倒人。疲劳、损伤、器械和资源变化须影响后续选择，不每镜复位为巅峰状态。

- 接触可以短暂，出招与回收应有区别；剑枪相碰后的分离、偏转、换线或蓄势继续推动动作。不要每次碰撞后都双人摆成静态交叉兵器造型。
- 退避必须有可见原因：枪锋仍占据进入路线、气劲传到脚下、护架受力滑退、为了绕开扫击抢到侧位。进两步/退两步的镜像走位不构成压制。若因威慑退让，应先建立被识别的威胁和角色判断。
- 写力量因果：发力者的动作 → 能量/器械的路径 → 对手或环境的受力 → 后续状态。水幕凭空出现、先后退再出剑气、只闪一下光便宣称破防都不成立。
- 允许有意的蓄势、试探、悬停、命中后短促强调或决胜静止；要说明停顿期间仍存在的威胁/变化及下一动作触发。不能把生成失败造成的一两秒停住，事后改名为“高手气场”。也不要把全片都加速来遮掩缺少动作。

### 检查威胁、目标与机会

主要出手应指向当前人物目标、能力作用点或有战术意义的环境位置。贴身时砸地并非禁用，但须说明并拍出为何选择它：掀掉支撑、阻断路线、迫使对手腾空等，且收益与暴露的空档成立。不能为展示一个特效而让敌人近在手边却毫无关联地看着砸地。

在双方都能行动的时间内，转身、背向、长蓄力和招式回收形成的机会应被利用或有可见的未利用原因：余势仍封路、另有威胁、距离不足、伤势、诱敌或已建立的角色意图。检查感知范围，角色不必全知、每个空档也不必成功命中；但不能默认整场轮流等待。护送者可以边挡边夺位，追击者可以改变目标，不固定成“只防御/只砸地”的循环。

### 设计速度变化与冲量

需要将打击感、力量感、速度感落实到身体、衣料、空气与环境时，读 [分层表现方案](impact-force-speed.md)，按当前体裁选择响应载体和时间先后，避免全部同时抖动或发光。

动作速度来自姿态随时间的变化，写“normal speed”只说明没有播放慢放。关键爆发可明确短促收束、突然加速、迅速抵达、接触后身体或器物继续传力、失衡/回收立即引出下一动作；连击和借势不需要每次重新大蓄力。用重量感的预备与余势、轻灵的短弧变线区分风格，避免所有过程匀速插值。

为关键事件给适量相对节拍或粗时间窗，按所选模型实际支持的方式编译，不塞每帧命令或固定每秒招数。根据有效动作决定镜头长度；单段最长可生成多久，不等于每次都应占满。若一段只有一击和等待，先缩短/重编动作并设计连续剪辑，不能通过拖慢表演填满8–15秒。长请求导致摊慢属于待实测的可能原因，不当成所有模型的确定规律。

力量须体现为接触或能力作用、受力形变/位移、攻击者的跟进/反冲和环境余波的合理先后。声音的短促接触点、材质主体和衰减帮助感知冲量；不以全程低频、每击震屏或运动模糊掩盖软动作。先正常速度看是否可感，再用逐帧辅助定位先倒退后接触等错误。

## 4. 让环境和交战路线参与战斗

先用简图或短句建立有用区域及相对方向，再规划本段如何穿过它们：庭院中央 → 池沿 → 回廊立柱 → 高阶。区域数量按剧情选，同一地点也能有丰富变化；空间变换要有行动理由，不能随机换背景。

角色借墙/踏水、利用柱间遮挡、沿阶台改变高度；对手动作改变可行路线。风、袖摆、落叶、水纹、薄雾或碎屑随动作累积、传播、衰减，留下下一镜能承接的状态。干净画面优先让少量、方向明确的环境响应显出力量，避免浓烟盖住接触点。

追踪相对位置、朝向、动量、正在进行的攻防、武器接触/握持、离地或落脚状态、残留水纹/气劲/损伤。状态不止是“蓝左红右”。角色绕行后可以换屏幕位置，只需用可读的移动/建立镜头交代。短时战斗不必凭空改变天气、太阳方向或时段来显得丰富。

将身体朝向、移动目的地、视线和银幕方向分开。冲向门口时胸腹/脚步可朝门，短暂回望追兵不等于整个人背向目的地倒跑；有意后撤则明确面向威胁撤至何处。用门、柱、屋脊等稳定地标确认追逃先后和高差，不在绕机位后继续硬套“左/右/前/后”。接下一段前查看实际支撑脚与支撑面，不能把站桥面的人误读成站在同伴所在的高台上。

## 5. 摄影跟随战术，景别展现尺度

按段落决定观众需要看全身招式、位移路径、力量范围还是破绽。至少要在创作目标要求时找到对应的可见镜头，不用固定比例、每几秒切镜或全程抖动代替摄影设计。

| 要让观众感到/看懂 | 可以采用的镜头设计 | 约束 |
|---|---|---|
| 远距压制与高速横移 | 全景/全身中远景沿交战路线侧向跟拍；前景柱子经过，池沿与远山出现视差 | 两名角色与攻击路径需可读，不能让快摇遮住关键招式 |
| 宽弧/重势或柔性器物展开 | 随主轨迹横移，保留驱动端、远端、主体支撑及受影响范围 | 不能只拍末端光效却看不到动作如何产生 |
| 转线、攀跃或非人形换层 | 动作中切换到斜侧全身视角，或升起/后拉揭示新高度与落点 | 用同一动作方向和地标重新建立关系，保留该身体结构的运动逻辑 |
| 大范围气劲与对抗 | 拉开或升高到可看见双方、力量传播及环境响应的画幅 | 能量不能一亮就切走，须让观众看到作用 |
| 破绽与决策 | 短促靠近眼神/握持/剑尖，再在动作中回到可读全身关系 | 特写提供信息，不能把整场打戏拍成表情和火花 |

摄影描述含起始构图、移动方向/触发、结束揭示的信息；同时写主体如何运动。镜头跟拍时人物可相对居中，但前后景应有符合路线的视差。锁定机位仍可用于展示完整招式或强调蓄势，只要它服务该段体验。

空间清楚不要求每个镜头把所有角色、起点、路径、终点同时塞在全景里。先建立相对关系，再按体验选择景别、机位距离和视角：宽景显出交战尺度，斜侧全身显出躯干发力，前景掠过显出速度，短接触镜突出力的转移，随后回到可辨的新空间。关键事件不能全被特写、遮挡和切镜省略。

摄影机的速度与角色速度共同设计：例如贴近地面让近柱快速掠过、远景缓移；先让角色从远处迫近画面，再接侧向跟拍；腾空时以抬升/后拉露出下方落差。持续等距同速跟拍可能抹平逼近感，不是一律最优。每次变化写观众得到的关系与节奏，不堆“拉远、环绕、摇晃、升高”并要求同镜同时完成。镜头转角与动作方向要有衔接，不自动把视角变化误判为角色倒跑。

## 6. 拆分生成时保存动作，不冻结画幅

生成单元不是摄影镜头：一次请求可包含模型实测能承担的连续动作或镜头组；一个摄影动作也可能跨多个请求。不要默认“60秒 = 12个5秒，每段一招”。按自然动作句与剪辑点分配时长，并遵守用户硬件及当前模型约束。

先设计完整动作链与摄影，再用参考/分镜降低执行难度：

1. 同机位连续动作可用经过检查可用的选片状态/视频承接，明确正在进行的动势及下一压力来源。不必选文件最后一帧；坏终态先返工或选择合理剪辑点，不能让错误姿态/方位代代继承。生成尾部是剪辑余量，不要求为了交接站定半秒。
2. 需要换角度/景别时，依据输入模式与实测稳定性选择：独立镜头的文本构图配身份参考、连续运镜、新构图关键帧或新视角参考。现有图会锁错视角、文本难以建立关系时再准备新图，区分身份、状态、摄影构图的用途。方案确实需要新图而尚未生成时标待绑定，不假装上一末帧同时就是新机位。
3. 支持并已验证镜内切换的模型可明确分镜；能力未知时用独立镜头在动作中匹配剪接。对上一末帧逐段写“完整保留构图”，会持续继承同一机位，不能只在文本末尾加“史诗运镜”解决。
4. 先减少独立支线、对白与装饰，再把高负载动作按连续因果拆成多个视角。复杂兵器接触可用动作/姿态参考；保留至少能看清关键动作和后果的证据，不能全用碰撞特写或闪光替代对打。

最终执行提示词保留：关键参与者与器物/能力身份、各自任务及连续动作、作用路径、空间去向、摄影变化、核心特效/声音节拍、下一镜需继承的动态状态。身份细节尽量交给已绑定参考，减少重复“脸清楚、衣服完整、场景不变”等限制对动作与摄影的挤压。正常转身、背影、遮挡不等于身份丢失。

## 7. 战斗专用审片与失败去向

先查设计，生成后以连续播放为主；抽帧只补充姿态/接触检查，不能证明动作之间连贯、速度自然或不存在停顿。每次指出问题，记录时间窗、实际发生、违背的核心意图及返工措施。

| 必查项 | 失败信号 | 修正方向 |
|---|---|---|
| 力量/现实尺度 | 与声明等级不符：高武缺少超常运动或作用，现实题材却凭空加入能力；核心作用范围未出现 | 按本片规则在动作、环境和摄影中兑现尺度，不用体裁标签代替观察 |
| 能力与角色辨识 | 换掉器械/身体名称仍是相同挥砍或发光；其他人只等招 | 重写结构驱动、动作机制、代价与同时任务 |
| 连续性与速度 | 每次接触后双人闲置；重复起手；移动没有压力来源 | 重接下一动作、缩短无用途持势、重做因果缺失的片段 |
| 场面与摄影 | 全程同一距离、画幅、平面位置；运镜只在提示词里 | 修改运动路线和构图参考，按摄影目的重分镜 |
| 攻防结果 | 没有逼退、闪避、失衡或破防，后续却按成功继续 | 核心失败先返工当前镜头组；只有不损害核心体验且经检查可用的偏差才可调整后续承接，不能仅靠续写放行失败素材 |
| 特效与声音 | 只有闪光/轰鸣，没有展开、交互、材质和空间；声画永远满强度 | 按事件检查效果生命周期与声音主次，实际观看/听审后确认 |
| 场面与代价 | 赢输无关任务；前镜负伤/透支后下镜满状态；配角排队等主角 | 重排共同时间、参与者目标和能力变化，让转折兑现 |

用户要求的力量等级、连续攻防与动态摄影属于该项目核心要求，不能被人物好看、无变形、格式校验或时长达标抵消。没实现的关键动作不得事后重新命名为“恢复/铺垫”来算通过。正常按实际状态修正细节；会丢失核心目的的修改必须标为偏离并返工/重设计。

尤其查三项：攻击是否指向有意义的目标；对方是否在同一时间有效回应或利用机会；爆发、接触与后续是否有速度和力量反差。出现近距离无理由打空处、敌人背身时无因等待、朝向与逃跑路线矛盾时，先定位参考/提示/生成哪一层失败，不靠为失误续写新剧情通过验收。

先在已有授权内试能暴露本项目风险的连续小样：例如独特器械交锋、多人任务转移、关键能力展开，或载具运动中的空间/声音变化；现实题材不必展示超常力量，单人追逐也不必添加对手对撞。具体长度按风险与模型选。反复失败时改变参考、动作拆分或制作方法，不把不同场面都降成简单近身互砍。用户要求先交完整粗剪时可保留标缺陷版本，但技术完成与创作达标分别报告。

## 8. 选择不同机制的示例

目标包含高武或细致力量交互时，先对照 [实际画面案例](high-martial-visual-cases.md)，选与场面任务有关的机制与尺度。需要固定高差、操控或接触关系时使用 [动作关键帧方法](action-keyframes.md)。素材的丰富度看能否比较发起、作用和后续，而非同一爆发画面截了多少张。

参见 [多类型动作示例](action-examples.md)：柔性兵器与盾的护送、领域失效与非人形压力、载具上的多人脱困，以及作为局部历史案例保留的剑枪交锋。选择与本项目机制相关的例子，不把原场地和动作套给所有题材。
