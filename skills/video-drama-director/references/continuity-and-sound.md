# 连续性与声音因果

## 资产身份和状态必须分开

参考资产回答“这是什么、长什么样”，状态回答“此刻它在哪里、连接谁、发生了什么”。物件默认图不能反复用作每次动作的起态。

反复出现的物件记录适用字段：物理ID与位置、持有人、朝向、连接对象、电源/机械能、开关/灯态、指针角度或可辨识视觉读数、损伤/湿度、最近改变事件、可发声条件。多人互动另记录屏幕方向、手的归属、谁知道什么、谁已经听过台词。

文字或读数承担选择、悬念与揭晓时，还要区分空白、填写/变化中、完成及观众何时可读。最终结果正确的汇总图，仍可能提前泄露决定、把本人选择改成他人代填；分别按实际操作人、纸张/屏幕身份和发生时点绑定，不用终态底板覆盖前面的过程。有意让观众先知或倒叙揭示时按该叙事设计安排，不能仅因文字准确就认定揭晓时机正确；静态底板就绪也不证明动态操作、透视和可读性通过。

补给、库存或可分配物品还要核对用途、使用人数与可见份量是否支持情节，再记录取出、交接、消耗和余量。数量前后一致也可能在故事上不合理；用户质疑准备不足时，缩小容器不能替代补足准备。只看到顶层或部分内容就记录可见数，不虚构遮挡后的总量。有意限量、定量用药或资源耗尽另按剧情依据处理，不一律把容器装满。

两台外观近似的仪表即使脚本赋予不同ID，观众也可能当同一台。给它们可辨识的固定位置、壳体/指针颜色、大小或邻近物；用建立镜头说明，不能靠后期解释“其实是另一个表”。世界内必要标记可用真实资产/后期制作解决，生成字幕与道具标记不是同一个概念。

## 状态提交流程

1. 设计镜头初态、触发、变化、终态；每个改变都能指向事件。
2. 初态取经检查可用的上游选片实际状态，同时核对支撑面、面向、相对高差与目标方向；文件真实不等于状态读对。首帧约束按执行面支持核实，锁定画面也不能保证后续运动会发生。
3. 查看动作全过程和末态，记录实际发生了什么；没测角度就记“上右→略下降”或“未知”，不编造数值。数值量测保留参考轴和证据。
4. 核心条件成立、版本可用后提交剪辑点处的实际状态，再构建下一镜参考/起态；不必使用文件最后一帧。失败素材保留为诊断，不能仅为凑时长进入生产依赖。上游被重做或裁掉动作时撤销下游依赖并复核。
5. 若起终态不符：修镜头、重绑参考或重设计有理由的复位/转场。不能默默重置状态，也不能把终态图复制整段假装发生动作。

涉及接触/受力：准备—接触/作用—运动—结果或下一动态阶段；只有实际停止时才以静止结束。需要多关键帧时至少覆盖会被误读的接触/转折，不仅两张“前后状态”。风格化物理也应服从已建立的作品规则。动作场景按需续记伤疲、资源消耗、能力维持、控制对象及特效残留，并让这些状态影响下一步选择。

支撑面和固定场景也是连续性对象：人物起身、后退或受力时，核对身体支撑点与地面、座椅、墙体地标的相对关系。相机移动产生的视差不等于家具位移；有疑点时比较共同参照与连续过程，不能因人物仍在画幅内就忽略无驱动的支撑面滑动。

## 换场、入场与反打

剪短后重新检查事件还剩什么：若交接被裁成一个点头、出门被删成另一地点的站姿，原先的领取或到达事件可能已不存在。保留能读懂的触发、持物变化和行动去向，再接新地点的进入或到达；可以省略无信息的路程，不要求拍完整旅行。时间标签、空镜、淡化和声桥只辅助交代，不能替缺失的关键动作或解释同一人物像同时在两处。旁人接替前一人的画面位置时，先交代原人离开、新人从何处进入；原本在画外的人也应有可理解的路线或声音，而非无因出现。

反打沿同一世界位置检查桌椅、人体朝向和固定地标。机位越到另一侧，画面左右与可见前后墙会改变；不能同时保留旧画幅左右、前方地标和新反拍正脸。近似景别相接还要比较人物相对门框、台沿等地标的位置与动作阶段；无理由跳位就修源、匹配剪辑点或改为有任务的切镜，不能用过渡效果掩盖。以时间省略或风格化跳切为目的的作品另行建立可辨识语法，不机械补每一次进出门。

## 声音分类与检查

连续剧情的配乐优先在后期统一编排，避免各生成片段自带随机音乐造成断裂；保留对白/环境/音乐/效果声的可调整关系。喜剧停顿、Q版设计声、对白闪避与跨段音乐处理见 [表演与后期声音](expressive-comedy-and-post-sound.md)，不把增加音效数量等同于声音更生动。

| 声音类别 | 需要说明 |
|---|---|
| 画内现场声 | 可见物件/人物、触发、发声阶段、停止条件、空间距离 |
| 画外现场声 | 真实画外来源、位置方向、人物是否能听见、与前后镜头的关系 |
| 主观声 | 谁听到、触发/心理意义；需要时用反应、视角或混音区分 |
| 非现场配乐/设计声 | 观众听到但人物不听到，叙事用途与进入/退出点 |

电气/播放声核对电源、连接、播放状态和声音路径；机械声核对接触、压力、摩擦或剩余惯性。不是只有画内才能发声，也不是所有运动都必须响：画外来源、无声动作和主观体验都可成立，但应被设计清楚。

异常耳机案例：如要表现“未插接仍传来未来录音”，先让观众可见插头断开，再让声音出现，人物摘下/确认并反应，后续解释或兑现。明确声音是主观听觉还是现实耳杯声；不能一会儿房间扬声器、一会儿耳内声而没有规则。普通未供电耳机则不应产生播放声。

夹子案例：手碰桌边使夹子滑落 → 接地撞击 → 短暂弹跳/线柄余振 → 静止，声音随每次接触衰减。若跳过触发动作，仅写“夹子移动并响”就容易变成自发/循环运动。落地余振不能解释一直摇摆。

对白和环境需共享空间：距离、朝向、遮挡、混响、噪声和人物呼吸相符。声画桥接保留同一事件：声音可以先入或延续到反应镜头，但不能重复播放同一句/同一下撞击作为另一事件。

源片对白正常而拼接后从某个边界起消失或变成噪声时，先查封装与音轨兼容性，不先重做表演。不同声道布局、采样率或时间基的音轨不能仅因编码名称相同就直接流复制拼接；可逐片独立完整解码为统一格式的PCM，按实际选片时长装配后统一编码。新源片需重新核对实际对白边界，不能用旧版预估窗口静音或截短新声音；再检查最终导出中的对白及跨段边界。预期无对白的插入中，ASR识别到文字也可能是假阳性，不能据此添加台词；波形、相关性与ASR仅作定位，不代替最终听审。

极短应答、同音字和句前停顿可能使整段ASR漏词、写错字或把首词定位到静音。保留原声与原始转写，必要时用不提示目标词的独立裁段复核，并换算回原时间轴；声能与可见嘴形可辅助缩小范围，不能单独证明说了什么。修订转写或时码须附原证据和理由，不能把预期文字写回ASR来制造通过，也不把未听辨的字音报告为听审确认。

源PCM完整但终片同窗对照异常时，还须排查滤镜、动态处理或编码产生的时移。可比较原始同窗结果和对齐后的诊断结果，定位造成偏移的环节，再修补时序或移除已确认冗余的处理；不能只移动检查窗掩盖真实漂移、缺词或截断，也不普遍禁用限幅等正常工具。修后重新核对终片与参考的实际同步关系；信号相似仍不等于嘴型、情绪或听感正确。

声源正确之后，还要判断材质、运动、角色状态、主次与动态对比是否有表现力。特效/动作声承担关键体验时读 [特效展开与动作声音](effects-and-action-sound.md)，设计声画节拍；不把音轨存在或每次撞击配了声音当作听感丰富的证据。

## 固定歌曲、录音与音乐主导段落

用户要求保留现成歌曲、演唱或固定录音时，先把完整声音作为独立制作依赖，区分“候选文件已生成、音色小样认可、完整内容听审、采用版本锁定”。短样认可某种音色不能替代整段的漏字、断续、长音、换气与乐句连接检查；母带指纹一致只证明用了同一文件，不能证明源音频无损或好听。无法连续听审时提供独立可播放音频和检查点，保持候选状态，不以技术成功冒充声音已通过。

音源经过提取、分离、转换或混音时保留可比对的阶段：原始录音 → 提取/分离人声与伴奏 → 转换干声 → 混音 → 成片音轨。发现断续、缺字或音色异常，按同一时间窗找最早出现异常的环节，再决定修源、重分离、重转换或改混音；不要只改视频、提高视频采样步数或用更大伴奏遮盖上游损伤。伴奏无需换音色时保留独立原轨，操作名称、模型换到别的界面或成功输出文件都不是修复证据。核实工具究竟保留原演唱的时序并转换目标音色，还是提取旋律后重新演唱/编曲；后者可能需要重新编排画面。

采用固定音乐后，分别登记音频参考输入、模型实际输出与最终采用音轨。按执行面能力只保留需要的生成声音，在后期连续装配所选完整录音；不让每个视频单元重新起歌、重唱或因换镜变速。用户要求原生演奏或有意断奏时按其目标设计，不强制静音或套用固定母带流程。

音乐主导剧情按乐句、情绪转折或叙事段落给可见事件分配作用：谁向谁表达什么，主动行为怎样引出察觉、回应和下一变化。检验中后段是否仍回应当前音乐与人物关系，而不只看开头朝向正确、剪辑点匹配。可以呼应、反讽或保留安静聆听，不必逐字表演歌词、每拍加动作；需要的是有目的的关系进展，不能用重复靠近/推开或空等填满整首歌。

先写正确条件和动作；是否使用独立negative字段取决于模型。不要堆“禁止移动、禁止手、禁止一切物件”后又要求操作/互动；正向主句应能独立说清发生什么。约束只保护关键身份、结构和因果，不把所有变化都冻结。
