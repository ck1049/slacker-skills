# 群体、环境与道具关系

用于次要角色、NPC、人群、场景条件或操作对象影响剧情的镜头组。依据项目创作与返工观察形成的设计方法，不是模型效果保证。简单单人镜头、刻意静止和安静场景只取适用项，不把整张表塞入每条提示词。

## 完整场景的行为关系

| 层次 | 选择可执行行为 | 与主事件的关系 |
|---|---|---|
| 主角与配角 | 当场任务、听者反应、支撑/视线/持物状态 | 谁发起、承受、回应并改变决定 |
| 近处 NPC | 穿行路线、肩背/袋子遮挡、让路或不让路、接触后反应 | 是否改变主角路线、平衡或可见信息 |
| 中远处群体 | 排队短步、走停节奏、不同方向、局部密度、等待/观看 | 场景压力在对白期间是否仍成立 |
| 环境 | 动作造成的遮光、衣摆/水面/门扇响应、连通路线 | 是否解释空间与作用，而非无关装饰 |
| 现场声 | 近远、连续/离散、遮挡/混响、进入与停止 | 是否与群体和动作共享空间 |

群体按少数行为组描述，不必给每名路人独立名字、参考图或对白。与剧情相关的单个 NPC 单独定义，其余承担低强度支撑行为。不要让所有人同步摆臂、盯着主角或同时说话。

拥挤案例：背包游客从近处挤过，两位主角屈膝移脚恢复平衡，帽沿和衣摆迟一点跟随；中景队伍仍短步向前，远景慢行。暂时的空隙随后被填上。铺石/栏杆提供位移参照，摄影跟随不能代替真实移脚。远处背景人群无需一律近身碰撞。

异类场景：急诊走廊里，护士推车经过使家属收腿让路，后景候诊者低声交流。诊室开门时走廊声进入，关门后被滤远。压力来自通行和空间，不照搬旅游人群的挤压动作。

反例：图书馆阅读、默哀、等待信号等有意安静可以长时间静止。按目的选择呼吸、换页、偶尔移位或低房间底声；不为了“丰富”添加人群和风沙。照片定格与活的现场应有可理解的剪辑语义。

## 空间要支持角色的决定

寻找座位/出口/掩体/证据前，检查可见范围是否已有明显、可达、可用的对象。旁边空椅与“找不到地方休息”冲突；被占用、隔栏不可达或用途不同则可能成立，但须让观众看懂。

发现远处角落可用：拥挤近景建立困难 → 视线/声音引导 → 摇移、后拉或过肩揭示距离与连通路线 → 移动或明确压缩路程的剪辑 → 到达坐下。不强制长镜头，也不以邻座空椅冒充远处新发现。

审查场景参考本身的空座、出口、队伍缺口、可用设备和物品。身份图、环境图、构图图分工；环境图嵌入主角定姿可能复制角色或冻结动作。NPC 服饰要区别于主角显著发型/披风/轮廓；不能仅加“没有重复角色”来补救已相似的图。

## 操作关系与镜头关系分开

关键动作写成：**操作者/支撑 → 手与连接 → 工作面 → 作用目标 → 可见结果**，再说明观察机位看见道具哪一面。

- 拍照：镜头朝被摄者；外部侧视可看背板，被该相机拍摄的画面里相机本体在视野外。相机举起但镜头朝外不等于完成合照。
- 打光/喷水/扫码：灯面、喷嘴或扫描窗口朝作用对象；对象和环境有可理解响应。操作手动了不证明结果成立。
- 支架、遥控、延时或别人代拍按故事与授权选择；三脚架不是通用必选项，新增功能不能冒充既有世界设定。

持续朝向/接触失败时，改一个能影响执行的变量：可读侧面/背面构图、接触/转向节点、分开的因果镜头、已授权后期方法。更多步数可能改善质感，不能修复错误的工作面和目标关系。

## 声音与持续行为一起设计

分清人群低声交谈声床、近处脚步/衣料与离散事件，不为每名 NPC 加可懂对白。主街进入遮蔽角落时，近处喧闹变成远处声，水声/房间声可更清楚；不要突然变成无空间的干对白。

配乐按作品目的和用户选择使用，无配乐也可成立。记录合法来源和必要署名；按对白与情绪进出、让出音量。后期加快门、铃声或敲击前核对真实触发与原生音轨，避免重复。对白说完且表情稳定后才选合照定格点；ASR或波形不能证明听过音效或音色。

## 审片与依赖

分别记录主事件、次要参与者行为、群体流动/遮挡/接触、空间可供性、工作面与目标、声音空间和跨镜衔接，用实际片段与相邻片段核对。群体计数、像素变化和镜头晃动不能代替这些观察。

核心是拥挤却群体静止、设备朝错对象却得到结果、近处已有空座却寻找休息处，属于机制失败；对白齐或画面漂亮不能抵消。阻断失败镜头的真实下游依赖，不取消无依赖的独立镜头，也不把同一完整构图重复锁到全片。

抽帧能发现部分实体、朝向和接触错误，不能认证连续运动或听感。保留实际提示词、输入、版本、选片与依赖；用户已有自主推进授权时不逐轮重复索取批准，收费、上传和发布范围仍依据已有授权。
