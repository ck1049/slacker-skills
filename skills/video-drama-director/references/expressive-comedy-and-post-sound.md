# 表演反差、Q版插入与后期声音

用于轻松、青春、喜剧动画，或用户指出画面平淡、希望加强反应与视听节奏的任务。目标是让人物接住事件，让视听变化服务笑点。这些是可选导演手段，不改变用户已选画风、身份、叙事基调或费用授权；写实严肃场景可只采用细微表演和声音留白。

## 1. 常规表演也要有变化

把“吃惊、开心、尴尬、佛系”改成反应链：先注意什么 → 眼神/手势怎样改变 → 对方怎样接话 → 最后如何继续办事。给听者和说话者不同任务，不让所有人带着定妆照微笑轮流念词。

例如认真说“只带了几本”，实际打开整箱书：说者继续平静整理；旁人先看箱子、再看说者，原先比“几本”的手指僵在半空。反差来自可见证据与不同反应，不必再加解释旁白。

按人物选择夸张眉眼、短暂石化、张嘴后没说出话、肩颈缩起、身体后仰、手势卡住、视线来回确认等。一次抓有效变化，留反应与回收时间，不是每句话都大喊、甩手、抖肩。夸张不能让聪明人失去常识、让礼貌者羞辱旁人，也不能让所有人变成同一种震惊脸。

## 2. 短促切换Q版或主观反应

在动画允许的基调中，让精美常规画风与极短的Q版反应形成落差。Q版是有触发点的插入，不是整段长期降格，也不是无原因地逐帧变脸。

写清**触发事件、谁的反应、Q版表现、回到哪个现实动作**。常用链条：

1. 常规画风铺垫，说者认真交代一件小事。
2. 正常物件镜头揭晓超出预期的事实，让观众先看懂。
3. Q版反应：大头小身、眼睛放大、下巴掉落、身体僵住；配简化冲击线、裂纹或一枚漫画符号。
4. 回到正常人物和同一场景，让平静的一方继续整理或提问，笑点落在反差上。

约0.5—1.5秒可作短反应的试剪起点，按可读性与笑点调整，不是强制时长、固定频率或每集配额。通常一个主要反应比撒满表情包有效；较长心理段落另有叙事任务时单独设计。

先核对人物何时看见或听见导致反应的信息，惊讶紧接这次发现；不能先体验完物件，再补演第一次认出它。若笑点要求人物以Q版说出一句惊讶台词，把吸气、重音、嘴型和整句声音放在同一次Q版反应内，不拆成无声Q版后接正常比例的平淡问句。采用时长按实际完整表演调整，可以超过上述短反应范围；只压缩经核对无叙事作用的空隙，不为套时长截词或加速整段对白。无对白反应、刻意的画外声或延迟反应另按其叙事目的设计。

Q版仍保留本人的脸型特征、发型、服装色块、眼镜和体态。保留当场到场者、左右关系、视线目标和持物；尚未登场的人不能加入集体反应。成年人的Q版不改写实际年龄或身份。多人的夸张方式应不同，淡定者也可保持正常风格，形成同框反差。

鼻涕泡、汗滴、豆豆眼、灰白石化、小灵魂等只在人物与基调合适时少量使用，笑点结束即收回；不永久加到定妆、不每人堆齐一套符号。用户引用某部动画时提炼比例、停顿、变形和反差机制，继续使用本项目人物设计。

心理小剧场、内心字幕与主观夸张须让观众辨认出主观性质。漫画雷电、碎裂或人物飞走若只是心理反应，现实恢复后不留下真实损伤、位移或道具丢失；若是剧情内真实事件，则按真实状态续接。

### 实现选择

将常规镜头、物件揭晓、Q版反应和正常恢复设计为可独立控制的剪辑片段，不强求一次生成同时完成换画风、复杂动作、多人对白和恢复。Q版可单独生成短片段，或在合适时用关键姿态图配少量后期弹入/停住/回弹；后者记为图形动画，不冒充生成出了丰富角色运动。

切换前后匹配背景方位、服装、道具和动作阶段。已有片长接近上限时，优先替换无信息停顿和重复镜头，不悄悄延长总片长或压快所有对白。后期声音与画风变化分工，不靠加一张Q版图替代全段表演设计。

## 3. 信息道具必须看得出“是什么”

角色印象依赖书、工具、文件、奖券或屏幕时，需要具体信息，而非仅有数量与花纹。先列必须可读的少量内容，再决定景别、字级、焦点和停留时间；前排关键内容读得懂，不等于整箱几十项文字都已核验。

技术爱好者的书可用明确数学、科学、计算机进阶书名区分类别，是否含课程教材遵守项目设定。书名在实际书脊/封面上，不用旁白或悬浮标签补救空白书。正常画面、物件特写和Q版前景中的同一本书继续使用同一内容，不能只修一个特写、反应画面又恢复无字花纹。

生成字样不可靠时，使用可编辑的书脊/铭牌/界面文字资产，按表面透视、遮挡、光照和运动合成；运动镜头需匹配跟踪，或重新设计稳定可读的插入。不能将平面字幕直接盖上去冒充真实印刷，也不把伪字当景深。图片修改沿用环境提供的合适图像编辑工具与授权。

按实际输出及目标观看尺寸核对字形、方向、数量和类别，留够识别关键内容的时间。提示词正确、OCR识别一项或放大可读，不证明普通播放可读。有误部分修正或列待办，不宣称“全书名已通过”。

字幕、标签或排字本身也会泄露信息：当笑点或悬疑依赖句尾关键词、停顿后补语或物件揭晓时，按实际声音与画面拆分展示，避免整句字幕先把答案亮出。只调整承载该揭晓的部分，同时保留正常阅读时间，不让所有字幕故意滞后。核对导出中的揭晓前后帧；ASR词界与近静音窗、可见发声等证据冲突时，回查原声局部及相邻时间窗，不凭全长识别结果截词或改台词。能量与唇形只辅助定位，不能证明听清了字句或笑点节奏成立。

幸运、能力或价值反转还需要比较基准和获得过程：先让观众理解共同规则、普通结果与人物预期，再揭晓例外，最后由不同性格的人接住。按剧情需要或用户要求展示相关参与者的实际操作；蒙太奇可压缩重复，但不能只从空桌切成已有奖品，就宣称每人完成抽取。连续记录各人的容器是否开启、物件由谁取出、已有结果数量和例外何时首次可见，避免提前泄底、重复中奖或凭空多一件。若悬疑有意隐藏过程，则保留可兑现的线索，不强制展示所有人的每一步。

## 4. 配乐按连续场景统一后期编排

默认在剪辑阶段为连续剧情铺配乐，除非用户需要模型原生音乐或剧情内演奏。可按场景换曲，但换点由叙事/情绪驱动，不由生成片段边界决定。分段生成优先保留对白与必要现场声，不让每段自行生成随机背景音乐；自然语言请求无配乐不等于模型必然输出无配乐，回读原片核实。

保留对白、环境、音乐、效果声独立轨道或可复现的合成参数，便于改剪重对时。轻松喜剧可考虑拨弦、木琴、弹性低音、简洁鼓组等，不固定曲风、速度或乐器。选择符合年龄、地域和作品气质的音乐；无变化循环、持续高能鼓点或幼儿化音色不自动带来青春感。其他题材按自身体验选音乐或留白。

先画声音节拍：日常轻推 → 揭晓前短暂抽掉或减弱音乐 → 反应处短重音 → 恢复日常节奏。只在笑点需要时停音乐，不每句都“刹车”。对白时适度压低音乐或做闪避，句尾留白和现场声可比加大配乐有效。

处理乐句、节拍、循环接点、淡入淡出与跨场衔接；交叉淡化不保证不同速度/调性的曲子自然相接。检查对白遮蔽、突兀音量变化、断尾、残留旧音乐和爆音，不只检查有没有音轨。

原片烘焙音乐时先确认能否拿到分轨或可用无音乐版本。不能把新音乐叠在旧音乐上、把全段降音量就声称去掉旧音乐；分离损伤对白时不得报告修复完成。必要重生成沿用实际授权，不由后期优化自动扩展。

## 5. 音效只强调关键节拍

区分物件现场声、漫画设计声和音乐点缀。现场声遵守真实触发、材质与空间；Q版的弹簧、短滑音、惊讶顿点是给观众听的非现场设计，不让人物莫名听见或回答。

关键事件选最能传达反应的一种声效，可配短留白。避免所有眨眼、转头、走路都叠声，不默认罐头笑声、尖叫或持续满轨拟音。原声已有开箱、脚步、鼠标声时先听清，别重复叠两次；音效不能把没发生的按键、接触或动作包装成发生了。

配乐与音效采用项目已有可用资源、原创或许可允许的素材，记录来源和采用段落。没有资源时保留声音设计，不把文档里的声效名称当成文件已制作；请求加音乐/音效不自动授权另行收费或下载不明来源资源。

## 6. 最短有效小样与审看

用包含正常表演、信息揭晓、反应、恢复及实际混音的小样验证，再按授权应用。保留原片、改剪版本和采用时段，区分参考图、图形动画、生成动作和完整声音后期。

连续看：反应前能否读懂铺垫与道具；Q版是否短促且认得出人；恢复是否自然；有没有未到场者、错书名或道具复位。连续听：关键字是否清楚；音乐跨段是否自然；声效是否抢话、重复或过密；抽掉声音后表演是否仍成立。静帧、字幕、时长和波形只支持各自检查，不能证明观赏性已通过。

### 异类情景自检

| 请求 | 适用处理 | 应主动舍弃 |
|---|---|---|
| 青春动画里“几本书”揭晓整箱研究读物 | 可读书脊 → 旁人短Q版 → 淡定者继续整理；音乐短停后一个反应声 | 未到场室友、空白花纹、长Q版和解释旁白 |
| 都市动画里角色推不开写着“拉”的门 | 先呈现门牌与用力方向，再拍手僵住与短石化，恢复后正确开门 | 用震屏音效遮盖把手铰链错误，或只靠旁白说门牌内容 |
| 写实家庭剧里父亲接过修好的旧物 | 手的迟疑、呼吸与短停；房间底声，音乐轻入或不入 | 擅自Q版、鼻涕泡与滑稽音效 |
| 紧张救援里发现器械连接错误 | 清楚的操作面与反应，连续环境声，必要时撤音乐突出判断 | 为“灵动”硬加搞笑符号，或用音效假装器械生效 |

这些是适用性设计检查，不是已生成小样或实测观感报告。
