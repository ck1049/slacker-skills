# 模型适配与制作降级

## 编译前的能力卡

记录模型/版本、平台/工作流和核验日期。逐项写为官方支持、当前项目实测、未知或不支持：单镜时长/帧量化、图片/视频/首尾帧输入、角色数量和绑定、音色/情绪控制、对白/嘴型、原生环境声、镜内切换、负面提示词、分辨率/帧率/加速设置。官方支持也不意味着某个构图实测可靠。

从当前工作流确认输入真正连上执行节点，参考图文件存在且内容正确；不能把规划字段当实际提交参数。自然语言提示词与执行参数分开。没有原生音频的模型使用后期声音计划，不能输出伪造的audio字段。

把参考的真实语义与官方模式一起检查：角色身份参考、起始构图、首帧硬约束、动作视频参考并不等价。文字写“首帧沿用”不能创造工作流未提供的约束。照片中的面向、脚步、间距、握持与文本冲突时先修输入，避免同时要求“完整保留构图”和相反方向冲锋。

## 两层提示词

导演层完整保留：场景任务、关系、动作因果、表演、空间/光源、声音来源、初终态、参考用途。执行层选择：

- **主要动作为重的模型**：构图、身份和风格更多交给起始图；文本聚焦主要运动、必要听者反应和一项摄影变化。用位置明确多个主体，按实际指南使用正向描述。
- **结构化多模态/原生音视频模型**：按官方字段/标签绑定角色与声音、局部时序和参考保留范围。只提交相关参考，区分角色身份参考与当前场景起态。
- **弱多角色/弱物理模型**：共享空间的构图图或短参考先建立关系；复杂接触分成准备/接触/结果镜头，用声音与反应连续串联。原生表演弱时把合法的同一角色对白音轨与画面分别制作并对齐。

同一导演方案可以编译成不同文本，不存在跨所有模型通用的最佳长提示词。H3任务优先使用当前官方指南或已维护的H3适配 skill；本 skill 不复制可能过期的片长、参考数、标签及接口字段。Runway/Veo示例也只适用于所查型号，不能扩展为该品牌所有版本。

## 丰富度与执行负载

先试一个主要事件和必要支撑事件。演员身份、接触动作、机械几何、运镜、背景运动、强风格变化同时竞争时，保护因果和已声明的项目核心体验，减少非核心竞争任务。高武战斗的力量尺度、连续攻防和摄影可能同时属于核心；不要把摄影统一后置为装饰。不是一律禁用多人物，也不是每镜都在固定远近不动。

低分辨率下细小微表情、暗部线索、细指针不一定可读：用合适景别、方向性光线、清晰轮廓和较大的行为设计保持可辨识；不能写一堆无法呈现的细节后靠字幕解释。硬件约束不等于单人独白：共享构图和分开的反应/动作镜头在同等像素也能工作。

多人、多肢、柔性器械、连续控制能力和多层特效按各自难点安排参考或拆镜，不能统统套双人刚性兵器模板。特效生命周期可分镜保留关键阶段；声音原生能力不足时保留后期声音单或可用分轨。分层制作、素材合成与声音后期属于实际制作步骤，须记录工具/输入和完成状态，不能靠写进提示词冒充已完成。通用导演原则不保证模型能精确控制粒子、声道、逐帧事件或分轨。

降载前明确不可丢失的创作目标。连续战斗中的进攻、应对和追击属于同一因果链，不按独立支线全部删去；高武不能默默降成近身慢速互砍。同类能力失败的替代顺序：减少非核心竞争任务 → 明确构图/接触/动态交接参考 → 重分镜并保证共同空间/时间 → 后期声画/合成 → 在授权范围内讨论模型或制作规格。换收费模型、下载大模型或升级环境沿用用户实际授权，不能由此 skill 自行批准。

身份参考、场景状态、当前动作姿态与摄影构图分别标用途。同机位延续可接可用选片状态；换景别/视角按输入模式和实测稳定性选择独立镜头文本构图配身份参考、连续运镜、新构图图或已验证的镜内切换。原图会锁错视角或文本难以建立关系时再补新参考，不把所有换机位都变成强制制图。不要让上一末帧的完整画幅逐段锁定全片；连续性还须承接速度方向、支撑脚/腾空阶段、未完成的压力与环境余波。确实需要新参考却尚未生成时如实标待绑定。摄影镜头、生成请求和最终剪辑片段不必一一对应；按动作节拍与可用素材裁剪，不固定取每段前几秒来凑时长。

参考续接只使用经检查可用的状态。动作摊慢时核对实际PTS/帧率与剪辑速度，再查参考动势、动作与片长是否匹配、慢动作语义、关键加速/接触/跟进和模型表现。按有依据的变量试验；24fps与正确播放速度不证明角色动作有速度感，也不能未经比较就认定加采样步数会修复编排。

裁切只解决不损害叙事的小瑕疵。若把操作手、共享物件、他人反应裁掉，则重评该场是否还成立；连续多个镜头都要靠裁脸逃避同类错误，应回到导演方案，而不是算作“质量通过”。

## 词库、联想和搜索各自的角色

小型条件词库帮助选技法：什么戏剧目的适合过肩、侧光、静止、手持或画外声；不保存几千词让每镜抽样拼接。创作前按“关系/空间/光影/运动/声音/状态”做短检查，输出真正采用的两三项及理由，不是要求冗长隐藏思维过程。

搜索用在具体缺口：该机械如何受力发声、特定历史场景/体裁摄影、某模型当前约束或失败。优先原始资料、官方文档、专业教育来源，记录验证日期和适用范围。不要每条镜头都联网找现成提示词，更不要上传用户媒体到陌生网站获取灵感。

用户明确要求搜索、视觉语言贫乏或反复失败时，按 [视觉开发](visual-development-and-previs.md) 做实际参考研究，并产出采用的形态/节奏/构图选择。不能用旧来源清单或一次关键词检索替代本次缺口的查证；也不把其他模型的正负提示习惯、时长或运镜能力直接套到当前平台。
