# 远程攻击与巨幅特效

高武、仙侠的核心表现能力应包含远距交锋和巨大作用尺度。按作品规则选择使用时机；用户明确要求时，须在代表性小样中实际验证，不能只以贴身互砍加火花代替。这里是导演设计方法，未替任何模型证明实现效果。

## 从战术到可见因果

先说明远程出手解决什么：封住退路、逼离高台、击破屏障、切断增援、远距截击或保护某处。分别定义发起者、当前目标、空间距离、传播方式、承受者的应对和新局势。目标可为人物或有战术意义的环境；打空地、毁无关建筑不能自动算有效交战。

远距不等于两人隔开站定对射。攻击在途时，对方应根据感知与能力规避、截断、借地形、变向或主动反击；有意诱导攻击偏向环境时，先建立原目标与改线动作，不能从生成落空后倒推战术。

## 区分能力机制

| 机制 | 可见结构与传播 | 交互与可利用的局限 |
|---|---|---|
| 离体斩击/投射气劲 | 从刃、掌或枪势脱离，有领先边缘、厚度、推进方向与有限尾迹 | 闪避攻击线、截偏、切开或以支撑/屏障承受；不能既已飞远又仍黏在武器上 |
| 御物/剑阵 | 控制者与各实体位置分离，编队、转向、数量与操控线可辨 | 分散封位、逐个突破、攻击控制者；不是一堆静止发光剑贴图 |
| 巨大实体化招式 | 拳、刃、兽形或法相具有轮廓、体积、结构分区与动作驱动 | 按当前规则压迫、踏落、追击或破裂；不要把巨大形体降成平面光圈 |
| 范围术法/领域 | 明确边界、传播或成形过程、内部作用和持续代价 | 越界、破锚、隔断、改变介质；不以满屏雾光宣称覆盖很大 |
| 地形/介质传力 | 波沿地面、水面或岩层传播，有先到后到和局部断裂来源 | 改变高度、切断通路、选取支撑；不是全场一起抖动 |

同一角色的远近招式保留动作语言与代价，但不要求每个场面都把以上机制轮流展示。

## 拍清距离、体积与力量

远距先建立源点、目的地和至少一个沿途地标。桥跨、楼层、树冠、舟船或山脊提供尺度参照；人变小只是一个证据，还要看攻击跨过哪些空间。攻击的速度来自实际传播和镜头视差，不能靠全片加速或长时间匀速漂移。

巨幅效果需有清晰主体与局部细节：主轮廓、内核/结构肋、薄边、次级流动按层级组织。前后遮挡、透视缩短、地面投影/反射与介质扰动帮助体积成立。亮度不能冲掉轮廓，粒子不能盖住人物与命中点；巨幅不等于复制一堆同样的光效。

结合 [打击、力量、速度分层方案](impact-force-speed.md)：空气和衣料沿传播方向响应，近处强、远处弱；受力建筑先在具体承载点裂开，再局部脱落、相邻结构响应。石块有可辨来源，留出缺口和受损终态。主要效果消失后，风、水、碎块和角色动量继续衰减，不能让巨大爆发长期冻结成背景贴图。

## 摄影与分镜控制

按观众要看懂的信息组织镜头：发起的全身驱动 → 展现路程的斜侧宽景 → 承受者应对与作用 → 新空间/损伤终态。可在一个宽景内完成，也可在动作中切镜。切镜后的攻击须从已经在途的位置接续，不重新发射、重复蓄力或瞬移命中。

拉远、抬升或换角度要揭示范围、路径或代价；近景提供发力或反应信息，不能省掉整段传播与作用。对巨幅形体，用相对稳定地标和层次遮挡保留可读性，冲击后的短促摄影反馈随力量衰减。

依 [模型图片预算与拆段方法](action-keyframes.md)，优先准备真正不同的状态：未发出、脱离源点、途中经过地标、应对/命中、结构破坏、效果已退出的完成态。身份参考和动作节点分别计数；时间槽不足就拆完整动作句，不能只提供多张不同颜色的爆发顶峰图。

示例设计：追击者从渠对岸高台发出有方向的巨大枪势，截击桥上携物者。携物者见到在途压力后跃离桥面攻击线，攻击穿过她先前的位置并击破后方石门，门体缺口和落块保留；落位后追逃路线已被改变。距离、脱离武器、主动应对、命中来源与余波应分别有证据。这是实验方案，不是模型已通过的样例。

## 审查与异类适用

审查源点/目标和沿途距离是否可读、攻击是否脱离并传播、巨大形体是否有体积与参照、对手是否同时有效回应、作用是否改变局势、余波是否退出、声画是否符合空间。核心项失败即返工，不靠美术精致、时长或文件存在放行。

异类检查：仙侠水域御剑阵可用舟船与水线显示覆盖，逐剑改线围截渡船，船上角色用风帆/障碍争取破阵机会；不照抄石门爆炸。巨兽攻城可用城墙楼层、人群撤离和承重点响应表现体量；不强加人形剑枪。现实题材按实际力量尺度处理，不因读到本参考就擅自添加术法。
