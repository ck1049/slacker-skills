# 场面、表演与视听选择

## 体裁决定选择理由，不决定统一套色

先写本片的观众体验、节奏变化、质感和视觉限制，再挑画风。下表是可调整的起点，不是题材标签到画风的硬映射。

| 体裁/目标 | 可用组织方式 | 表演与声音 | 常见误用 |
|---|---|---|---|
| 悬疑/惊悚 | 信息晚于视线到达；前景遮挡；后景异常；画外声引导反应；有目的的静止 | 抑制情绪、半句停住、屏息、辨认声音后再说；安静与突发声有对比 | 每镜蓝灰、慢推、嗡鸣，不发生新发现 |
| 情感/家庭 | 距离、手势未完成、共享物件；靠近/远离改变关系；柔或硬光按冲突选择 | 同一句话带不同对象和意图；吞回词、笑中停顿、回答延迟 | 人人柔光、人人哭、说话一样温柔 |
| 喜剧 | 清楚的铺垫与反应延迟；同框看见误会；揭示后短停；构图反差 | 一本正经与他人反应形成落差；节奏从局促到突然干脆 | 每句高亢、每镜夸张抖动/音效 |
| 动作/冒险 | 先建力量规则、双方打法、空间路线；进攻—应对—后果接入下一招；摄影揭示轨迹与尺度 | 呼吸和负荷随动作变化；撞击/摩擦绑定受力；连续压力与有意停顿形成节奏 | 每镜一招后站定、气劲只有装饰、快切掩盖没有动作 |
| 奇幻/科幻 | 新规则通过行为和代价展示；现实触感与特殊现象有对照；视觉母题变形 | 异常声音有世界规则或主观听觉标识 | 发光漂浮一切、任意违反已有设定 |

画风同时考虑受众、平台、素材与模型实测：写实、二维动画、三维卡通、水墨、定格等都可承载上述体裁。用户已选风格优先。列出色彩/材质/运动质感/镜头语法的少量锚点，避免把题材切换误写成每镜随机换画风。

关键角色与道具按 [视觉开发](visual-development-and-previs.md) 决定轮廓、衣装层次、材质工艺、持握与动作适配。颜色与类别只够作身份标签，不等于完成角色服装或英雄道具设计；也不能把所有风格都改成朴素练功服。

## 先设计关系，再安排画面

场景卡可用短段落或表格：戏剧目标与阻力；进入/离开本场时的关系和信息差；平面位置、关键物件、行动路线、面向、视线与轴线；互动链；观众先看什么、后发现什么，下一镜接什么未完成信息。

台词可跨过听者反应、操作细节或空镜，不必每句话都全程拍说话者。用双人同框建立共同时间，用过肩/反打保持对话对象，用反应镜头显露信息差，用物件镜头展示真正的证据。先保证空间可懂，再追求漂亮角度。

不要把“单镜一个主要戏剧事件”误读成“只能有一个演员”。一个人在回答时，另一个人可保持手势、转移目光或停止操作；这些是同一事件的反应，不是相互竞争的新剧情。

同理，“夺回主动”可包含完整的一串攻防动作。战斗不要机械套用对白中的目光—短停—回答节拍；按 [战斗动作、空间与摄影](combat-and-action.md) 组织持续压力、身体运动、环境响应与摄影。写实/干净的美术选择不限制力量尺度；身份一致不要求每镜露正脸或维持相同画幅。

## 有动机的画面层次

每镜选择真正服务信息或感受的层次，不强制全部添加：

| 维度 | 写成可执行设计 | 必须回答 |
|---|---|---|
| 主体/微表演 | 目光先落在他人手上再抬头；话到一半收回伸出的手 | 行为如何改变关系？ |
| 前景 | 对方肩背、门框、局部遮挡；景深与位置稳定 | 让观众代入谁，或暂时隐藏什么？ |
| 后景 | 他人延迟反应；设备灯态；可读的空间路线 | 为什么观众需要注意这层？ |
| 光线/阴影 | 窗侧光方向、实践光来源、阴影落点；角色移动后的遮光 | 光源在哪里？变化由谁/什么造成？ |
| 摄影 | 景别/高度/方向；按场面选择跟随、逼近、后拉、横移、升降、拉焦或锁定，幅度和速度有目的 | 新构图揭示什么，或如何传递感受？ |
| 抖动 | 与奔跑、撞击、主观不稳相关的幅度变化 | 是否会毁掉关键信息和跨镜匹配？ |
| 环境/粒子 | 雨滴、风、灰尘、蒸汽随环境/动作变化；范围和密度服从作品体验，层次有主次 | 受力/光照是否成立，是否抢走注意力？ |
| 隐喻/母题 | 相同物件在不同情绪/状态下再出现 | 意义有推进，还是又重复一个空镜？ |

最简导演句式：“观众先看A的手停住，B才注意到；镜头从两人中景小幅移到B，前景保留A的肩，远处门口仍在画内。”这比“电影感、丰富细节、震撼运镜”更能约束可见结果。

## 声音身份与表演卡

身份卡固定声线、年龄感、口音与参考音频；表演卡随当场任务变化：

| 字段 | 例子 |
|---|---|
| 对象与意图 | 说给陈默听；争取他暂停操作，并遮掩自己的恐惧 |
| 起点→转折 | 努力平静 → 看到他伸手后急促制止 → 确认停下后松气 |
| 语速/重音 | 开头快，“先别碰”清楚短促，后半句减慢 |
| 停顿/呼吸/尾句 | 制止后一次吸气；问题尾句悬住，不每句同样下沉 |
| 微动作 | 身体先前倾；看向操作手；确认停下才看脸 |
| 听者反应 | 陈默手停在按钮前，先看她再收手；不是机械点头 |

语速/音调描述相对本角色常态，不任意变成另一声线；不要把“冷静”“急切”等标签当全部表演。需要较长情绪发展时以镜头组/多句弧线安排，不在两秒内要求五次情绪切换。

快慢、轻重、停顿、距离、环境噪声与句长共同影响听感。对白叙事有变化时，环境/音乐也应让出或加强注意力；不能每镜同一声床同一干声强度。静默可以有戏，前提是人物仍在感知、决定或等待真实结果。
