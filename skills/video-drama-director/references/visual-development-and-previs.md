# 视觉开发与动态预演

用于关键造型、复杂动作/奇观、新题材与连续失败复盘。以下是导演制作方法，不是工具能力承诺。按任务深度使用，简单日常单镜不必另建概念工程。

## 1. 先找看得见的依据

用户要求联网时实际搜索。自身对目标效果缺少具体理解、连续输出仍同质或审美失配时，也应先补参考，不继续添加空泛形容词。优先制作方分解、动作/摄影/美术创作者访谈、官方设定图与实物资料；[来源索引](creative-sources.md)是入口，不是永远只用同一部片的素材库。

围绕当前缺口选择少量机制不同的案例，记录链接、实际读/看的范围、对应画面或时间段、采用的选择及不采用的部分。看形体、材质、运动与镜头关系，不只摘“史诗、电影感、能量、动态摄影”。只读文字时标文字依据；静帧只能支持造型/构图，不能声称已检验速度与声音。无法看视频可继续做来源支持的设计，但保留动态证据缺口，不下载远程媒体绕过展示限制。

把参考变成自己的明确设计：例如“前景有体积的水脊遮住腿部，卷边雾滴与内部折射区别开；撞到斜墙后沿墙分流，墙面留下湿迹”，再按题材变形。不要把片名、画师名或一组高分词当成全部说明，也不擅自把第三方图片上传为模型参考。

## 2. 角色和器物先做美术选择

新建核心角色/道具时，先给出与用户风格相容的明确视觉方案；确有审美不确定时，可比较少量差异明显的方案，再选定一套。用户已有设计优先，不为了测试抹掉其服装和身份。

| 层次 | 需要决定的内容 | 在参考图上实际检查 |
|---|---|---|
| 身份与轮廓 | 身份/文化依据、年龄气质、体型比例、发型；服装的肩腰比例、长短层次和活动开口 | 缩小后仍有辨识度；人物不是只靠青/白/红三色区分 |
| 衣装与运动 | 内外层、裁剪、连接与固定、硬软材质、重量；与抬臂、转体、腾空、持物是否相容 | 关节有空间，披挂不任意穿身；静态好看与运动可用分开判断 |
| 器物形体 | 轮廓、比例、厚度、重心/连接、握把或背带、正背面及其用途 | 人手怎样控制它，是否像能使用的同一件物；避免漂浮盘、无握持的装饰板 |
| 材质与工艺 | 主材和对比材质、接缝/包边/锻痕/织纹、反射粗糙度、使用痕迹 | 不把金属、布、皮都做成同一种亮塑料；细节集中于能看见之处 |
| 作品风格 | 色材主次、图案来源、标志性细节；是否与场景、光照、阵营一致 | 精简不等于廉价空白；华丽不等于全身随机花纹和发光边 |

按难点准备全身、侧/背面或器物正背面、关键持握/动态姿态图，不强制所有对象都有三视图。把身份设计与当场构图分开：一个普通三人站位图不能兼任人物定妆、道具精设和动作预演。低像素优先轮廓、比例、材质大面与少量识别点，不能借硬件理由取消美术设计。

制作前看实际参考：脸和手、持握结构、衣物与时代风格、场景地标、目标方向、身体朝向、多余人物/字样。有矛盾就修图或重构图，不让伪字、反向起跑和不合意造型沿末帧扩散。没有图像编辑能力时不要宣称已修，只能安排替代或明确待解决。

## 3. 用空间和时间预演，不用清单代替戏

先用短表、粗分镜或简图标出：各人意图、距离/高度、当前朝向、移动路线、攻击/能力的目标、对手同步反应、摄影机位置与下一个状态。复杂招式选关键姿态或构图节点，节点间注明驱动、加速、接触与后续；这只是预演设计，不是已生成的参考帧。

检查最危险的矛盾：贴身攻击为何绕去打地面；敌人转身或蓄力时另一人为何不利用机会；逃跑路线与胸腹/脚步是否同向；角色是否实际在能落脚的位置；下一个镜头是否把同一场地读成了另一种高差。合理的诱敌、克制、遮挡或能力限制可以保留，但应先建立，不能事后给失败补理由。

摄影与编排同时设计。空间建立镜头负责交代地理；关键动作镜头负责速度、重量或决策，不要求每个镜头一直装下所有人物和所有过程。一次大幅调度可由可读的匹配剪接完成，不崇拜一镜到底，也不以乱切代替实际动作。

## 4. 先证明难点，再扩大制作

把本次最重要的体验写成少量可观察条件。例如高武场面可要求“腾空改变高度与交战距离、远程封路迫使对手改变路线、爆发与反制连贯、摄影显出位移”；具体选项由用户目标决定，不能降低为“画面出现光圈”。

小样取能揭示这些风险的最短完整因果段，不为了时长要求把一次接触拖成长镜。按实际支持的输入、参考、时长与硬件制作。观察顺序：正常速度看节奏与力量，再查关键接触/方位，最后回正常速度；声音需实际听审。没有连续视觉或听觉观察能力时明确缺口，播放进度和波形只是技术证据。

核心失败的素材可存作诊断，不进入后续依赖。返工记录要说明本轮改变什么、预期改善什么、实际是否发生；同类失败后重构参考/动作/分镜，而不是一直换种子或加“更精彩”。继续任务意味着解决当前问题，不能把尚未通过的小样扩成一分钟后再写一份失败清单。用户明确要求失败合集或粗剪时按该目的交付，仍不得称合格样片。

能力确实不足时保留可比较证据与核心目标，报告哪种动作/视角/效果未实现及可用替代。不得用全片倍速、铺音乐、删除互动或取消高武能力来宣称体验达标。
