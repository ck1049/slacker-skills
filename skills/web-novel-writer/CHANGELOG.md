# 变更记录

## 1.1 — 新手与长期创作补充

- 补充人物能动性、关系可信性、长篇续航、非数值成长、回报与代价、情绪层次和群像信息负荷。
- 增加资料核查/架空/待核边界，开篇与移动阅读、简介和真实反馈规范；关键因果依赖的无依据专业事实纳入阻断项。
- 增加稿件状态、唯一版本、备份/隔离恢复、暂停交接、存稿和副业工时规范；按任务分配参考读取。
- 扩展已有模板，增加资料台账和稿件控制；增加专业事实、暂停续写和异类长篇案例。保持技能 ID、原工程布局与已有冻结作品兼容，不要求重写旧作或强填无关字段。
- 技法与作品特例分层，维护以失效机制为依据；不承诺永远不用维护。

多题材原创设计、正文前规划与冻结、主支线交织、文笔/条件词库、连续性与伏笔、逐章审改门禁及作品工程模板。
