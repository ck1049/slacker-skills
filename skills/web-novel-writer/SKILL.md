# 原创网文小说写作

让人物为自己的欲望作选择，让选择产生代价和下一场戏。用原创机制、人物关系和具体生活质感形成作品辨识度；题材标签、华丽形容词和结尾故弄玄虚不能替代故事。质量评审是可追溯的编辑判断，不保证签约、收入、流量或不存在全网相似作品。

## 工作约定

- 沿用用户的人群、题材、篇幅、尺度和授权。用户明确交由你决定时，直接给出有理由的选择并实施，不反复要求其批准名称或题材。
- 未明确的新书关键约束尽早集中询问；不需要用户回答的选择可以先做。只要求开头、短篇或改写一段时缩减规划规模，不强制建立长篇工程。
- 默认中文。16 岁读者也在目标人群时，按青少年可读尺度处理性与暴力；人物复杂性、爱情和社会议题不必幼稚化。
- 正文、创作笔记和剧透资料分开。正文不夹带“本章展示了”“这是伏笔”、评分、平台算法解释或作者对读者的命令。
- 未授权不上传正文、注册平台、购买参考材料或调用收费服务。连载发布前再核对目标平台的实际规则，不编造实时榜单或签约标准。

## 1. 确定作品承诺与原创差异

读 [题材、人群与原创设计](references/genres-and-originality.md)。把男频/女频当市场阅读期待，把玄幻/都市等当题材，把悬疑/成长等当叙事机制；三者可以组合，不能按性别套固定人格。

新书先落下：一句话故事、核心读者、主角想要什么、最难绕开的阻力、承诺的阅读快感、主题难题、体量与可持续写作计划。提出少量候选后用人物欲望、冲突续航和原创差异作选择，用户放权时自主定稿。

若借鉴知名小说，只记录高层技法，例如多人欲望交错、有限视角、公平线索或有行动的环境描写，并转换成自己的执行规则。不得沿用专属名词、标志句、角色组合、独特能力系统或事件顺序；改名换壳仍不原创。不要承诺复现某位作者的文笔。做题材惯例自查与参考台账，指出本作在机制、代价、职业、关系、价值冲突和结局上的实质区别；不会因为“职业冷门”就自动独特。

## 2. 正文前完成设计并冻结核心

使用 [故事工程模板](templates/story-bible.md) 和 [规划与冻结](references/planning-and-freeze.md)，完成下列最低交付后才开始第一章：

1. 世界底层规则：能力来源、限制、代价、信息可知性、资源/社会运行、空间与时间、禁止事项；用一个正常案例、一个极限案例和一个失败案例测试。
2. 人物卡：欲望、恐惧、利益、缺陷、行动习惯、声音、关系与成长终点；反派/对手也有可理解的目标和约束。
3. 全书因果大纲：起因、升级、关键选择、不可逆损失、高潮解决方式和结局；中段必须靠选择与后果续航，不能只列“遇敌—升级—再遇敌”。
4. 卷/篇章与支线计划：每条线的启动、交点、变化、收束；开放式连载也先确定阶段终点和核心谜题答案。
5. 开篇章节卡、伏笔真相表、叙述视角/文风规则、原创检查和开写前评审。

冻结核心规则、主要真相、关键人物动机和结局方向，记录版本与日期；局部场景与对白保留弹性。通过的是“可进入正文”，不是商业成功。用户已放权时，由你完成评审和冻结，无需制造额外确认门槛。

发现问题时先在既有规则内修改尚未定稿的场景，不以隐藏新规则或改过去的事实救场。确需调整冻结项时，按变更单说明原因、受影响章节/伏笔、最小修正和复审；保留旧版本，不悄悄改已发布剧情。尽量减少返工，不把“大纲永远不许改”当压过故事质量的死规矩。

## 3. 写前恢复记忆，设计有交织的章节

续写前先读最近定稿、当前状态、时间线、人物已知信息、关系变化、未兑伏笔和本章卡。笔记中的“拟发生”不是事实；传闻、人物认知和作者真相分别存放。读 [连续性与伏笔](references/continuity-and-clues.md)，使用 [连续性台账](templates/continuity-ledger.md)。

新增长期人物、规则、承诺、秘密、伤势、关键物件、关系转折或未兑现铺垫时必须记笔记；一次性景物不必逐条建账。每章定稿后更新状态和下一章交接，防止忘记谁在场、谁持有物件、谁知道秘密、时间走了多久。

读 [多线章节与读者参与](references/scene-and-suspense.md)，按 [章节卡](templates/chapter-card.md) 写章前计划：

- 一个主推进，并优先交织关系、生活/职业、对手行动、世界后果或另一条情节线中的至少一项。支线须通过共享人物、资源、地点、时间压力或选择反作用于主线。
- 记录开场状态、人物目的、阻力、可见行动、转折和离场变化；每场至少让信息、关系、局势或决策发生实质变化。
- 不硬凑两件事或固定切线比例。高潮、关键坦白和短场景可以聚焦一件事，但应同时有关系/代价/意义层次；在章节卡解释聚焦必要性。
- 普通章提供局部兑现，同时留下具体的未完成动作、选择或因果问题。不是每章都靠“他不知道更大的危险到来”骗悬念。

## 4. 写具体、克制、有个体差异的正文

读 [文笔与条件词库](references/prose-and-detail-bank.md)。描写首先回答：此刻的谁，为了什么，注意到了什么。外貌要参与行动、生活和辨认，物件要有用途与磨损，环境要影响人物走位、选择和情绪。

每场挑少量有意义的感官和细节，保持人物视角。用动作、物件使用和对话差异表现心理；允许简洁叙述直接交代，不机械禁止“他想”“她紧张”。长短句服从注意力与节奏，修辞须有具体对应，不能用所有段落都变成金句来冒充细腻。

词库按条件选用和改造，不能整段拼装。动作戏交代目标、空间、过程与后果；亲密戏表现双方的意愿、误读、边界和关系变化；群像角色有独立任务；幽默来自处境与人物，不复制流行梗或牺牲人物智商。

用可供推断的埋点、重复但变化的意象、相互矛盾的证词和有依据的误导增加参与感。隐喻可引发多种理解，核心因果和谜题却要能回溯验证。作者不能故意隐藏视角人物正在使用、读者必须知道的信息来制造廉价反转。

## 5. 每章必须审、改、再验

正文初稿完成后切换到编辑任务，读 [质量门禁](references/quality-review.md)，填写 [章节评审](templates/chapter-review.md)。能独立审读时安排不同审读者；不能时分轮自审，明确记录身份和局限，不能把自审说成独立编辑验收。

顺序：因果与规则 → 人物/关系/视角 → 主支线与节奏 → 线索公平及兑现 → 细节、对白、修辞与删水 → 原创/俗套/尺度。所有问题必须指向具体句段，说明读者会受到什么影响及怎样修；不只给一张分数表。

抄袭/近似换皮、硬规则冲突、核心时间或身份矛盾、为了反转强降智、未铺垫的万能解法、目标尺度冲突属于阻断项，任何高分不能抵消。核查水词、重复解释、空泛情绪、同质段落、刻板人物、尴尬说教、低龄动机和廉价羞辱等可修问题；“爽”不等于无需可信因果，“成熟”也不等于满篇阴郁。

先解决阻断项与影响阅读的主要问题，复查修正是否破坏其他段落。章节记录“通过 / 修改后通过 / 未通过”，未通过不标定稿，不依赖未通过的新设定扩写后续。允许用户要求交粗稿，但保留粗稿状态和待修项，不假称通过。

## 6. 定稿交接与连载维护

正文只保留小说。另存章评、实际变更、最新事实、伏笔新进展和下一章入口。定稿后再次核对台账与正文一致，更新进度；卷末复核主支线收束、人物弧线和全书规则，不为了字数安排无变化的副本。

将副业目标转换为可持续节奏：先完成可验证的小段存稿，再按实际工时调整周产量。初期优先一部作品、固定审稿时间与存稿缓冲，不用未经验证的收入预期催促发布。平台选型、作品上传和变现运营只有用户要求时才开展。

## 新工程建议

新长篇可按 [工程模板](templates/project-layout.md) 分离企划、冻结设定、大纲、状态、正文、评审和变更。开始第一部作品时先完整走一次流程，再用另一种题材的 [验收案例](examples/acceptance-cases.md) 检查 skill 是否被首作题材绑死。首次交付至少包含可续写的规划、经过评审的开篇、章后台账和下一章卡，不只留空文件夹。
