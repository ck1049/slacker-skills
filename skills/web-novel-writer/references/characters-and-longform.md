# 人物、成长与长篇续航

## 人物不是形容词集合

为核心人物确定：当前想得到什么、为何现在行动、最怕失去什么、愿意付什么、不肯越过什么、掌握哪些信息和资源、旧方法在过去为何有效。用会发生的选择验证“谨慎”“骄傲”“善良”，不要只列标签。

人物的错误需要可理解的来源：信息缺失、时间压力、利益冲突、习惯或情绪。聪明人也会犯错，但错误必须与当场条件相符；不能上一章擅长观察，下一章为了反转忽略眼前明确证据。无知不等于愚蠢，职业资格也不等于全知。

配角至少有一个不依赖主角的目标、一项可说不的边界和一种会影响剧情的行动。伙伴不是永远赞成，反派不是等着被反驳，女性不只承受评价或成为奖励，老人不天然全知，弱者不自动道德完美。角色的社会处境可影响选择，但不以身份代替人格。

## 关系与情感可信性

建立“双方想要—能提供—不能接受—彼此误判”的关系表。信任从履约和付代价积累，背叛有先前可辨的利益/压力，关系修复需要行动而非一次长篇道歉。恋爱、亲情、友情、师承和团队都适用。

重大情感转折先有至少一段具体共同经历或冲突证据；不是规定必须几章铺垫，而是检查读者是否认识这段关系。死亡、离别与伤害不能仅用于给主角加动机；事件后有现实后果和其他人的反应，不能哭完马上恢复。

允许人物作读者不赞同但仍可理解的决定。主题由这些决定及后果提出，不让所有配角轮流复述作者观点。幽默、体面、小成就、欲望和温暖也属于成熟叙事，不能把复杂性缩成全员冷漠。

## 续航发动机

全书要能持续产生**不同性质**的新问题。写明主要循环，并在每卷确认它改变了什么：

| 主机制 | 可持续变化 | 容易失效的重复 |
| --- | --- | --- |
| 成长/升级 | 新能力带来责任、资源约束、关系和旧方法失效 | 更强敌人、同样打脸、换地名重来 |
| 调查/悬疑 | 一个答案改变解释与目标，证据来源和合作成本变化 | 每章出现新谜团、原问题永不收束 |
| 职业/事业 | 方法改善带来更复杂的组织/客户/伦理选择 | 主角每次完美解决、同行永远无能 |
| 恋爱/关系 | 相互了解后产生新的承诺与生活磨合 | 同一误会复发、靠拒绝沟通拖长 |
| 生存/冒险 | 资源与地理约束变动，团队分工和规则组合改变 | 缺粮—抢粮—再缺粮，无长期变化 |
| 生活/喜剧 | 小目标积累改变共同生活、身份与关系 | 段子循环、下一章一切归零 |

对中段做“删除整卷”测试：若结局、人际关系、资源和谜题解释完全不受影响，该卷缺实质作用。每卷有自己的目标、峰值选择、代价和局部收束，不用持续添加新角色替代推进。

## 成长与回报

按作品承诺设计成长，不只数值：技艺、知识、地位、信任、资源、判断或接受边界。升级/修炼类需有门槛、练习、失败、成本、上限和可被反制之处；现实/恋爱类不强装技能树。

努力要有可辨回报，但不必每次都赢。局部胜利、方法被认可、获得证据、修复关系和守住选择都能提供满足；长期只受苦、每次胜利马上归零，也会违背阅读承诺。挫折使人换方法，不是作者不断没收成果。

敌我实力写成“具体条件下能做什么、不能做什么”，不要只靠称号。一个角色实力变强后，旧对手仍可能通过制度、信息、协作和不同目标成为挑战。高潮解法由前面建立的资源和选择组成，巧合可引出麻烦，不替人物完成最后解法。

## 情绪与章节节拍

每段剧情记录主情绪及转向来源：好奇→投入，成功→发现成本，误解→修复，轻松→具体异常等。不能仅在章卡写“感动”，正文却只有人物哭。转向靠行为、信息与处境，不靠反复提高形容词强度。

缓冲段仍有任务：收拾残局、确认边界、享受成果、接回日常、准备下一行动。不要让全部章节都等量紧张，也不要把日常视作天然水文。单章聚焦与多线交织服从当场情绪，不规定机械比例。

## 命名、视角与群像

重要人物姓名、称谓、年龄、身份和外貌锚点稳定；避免同一批登场者名字过于相近。新角色出现先让读者知道其当场任务，背景可分次给。群像按目标与线索组织，不靠一次介绍十个人证明规模。

有限视角遵守知识范围；切换在可识别的章/场边界，说明人物和时空，不在一个段落悄悄进入多个人内心。全知视角也要有稳定叙述约定，不为悬念选择性假装不知道已直接叙述的事实。
