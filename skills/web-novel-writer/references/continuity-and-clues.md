# 连续性、状态与伏笔

## 三层真相

作者事实是工程权威，但必须与定稿一致；人物认知可以错；读者获得的信息是正文已经呈现的部分。三者分列，禁止用作者真相自动给角色开天眼，或让笔记里未写进正文的线索成为解谜依据。

优先级：已发布正文 → 当前定稿正文 → 冻结设定 → 计划。两份高优先级资料矛盾时先修复并记录，不能用“最新文件”掩盖问题。对未发布初稿可改稿；对已发布事实不能悄悄改写。

## 应当记录什么

| 记录 | 更新触发 | 有用字段 |
| --- | --- | --- |
| 人物状态 | 受伤、离场、承诺、能力/身份变化 | 地点、伤势、可用资源、目标、证据章节 |
| 知识与秘密 | 目击、听闻、推断、被骗 | 谁、知道/相信什么、来源、可信度、何时可揭露 |
| 关系 | 信任、欠债、背叛、合作条件变化 | 双方、表面关系、真实利益、当前边界 |
| 物件 | 获得、交接、损毁、使用或复制 | 唯一 ID、持有人、位置、状态、数量、限制 |
| 时间线 | 跳日、并行、旅行、倒叙 | 发生时间、正文呈现时间、时长、参与者 |
| 规则与账目 | 使用能力、消耗、负债、失效 | 条件、实际成本、剩余量、是否永久 |
| 承诺与伏笔 | 埋下、强化、误读、兑现、作废 | 真相、读者证据、角色解释、兑现区间、状态 |

普通一次性描述不记账；需要跨章继承、会限制选择或可能被读者拿来推断的事实必须记。最近一章的交接页尽量短，长期资料按实体/主题归档，不能每次续写吞下全书全文来代替结构化记忆。

## 写前与写后

写前读取本章相关的冻结规则、人物卡、大纲、最近定稿、状态与未兑线索；说明当前章会动哪几条记录。缺资料时先找，不擅自给已有人物加年龄、亲属或秘密。

写后仅把实际写进定稿的变化升级为事实；拟发生、备选、未通过草稿继续保持计划状态。每项变化绑定章节与场景/段落锚点。章尾记录当前所有在场人物、当晚/当日时间、物件持有、欠账、认知差和下一章未完成动作。

记忆摘要也要审：漏记不可逆代价、把传闻记为真相、把试写当正式剧情，比没有词库更容易毁掉长篇。修改章稿后复查摘要、台账与后续章卡。

## 伏笔设计与公平误导

先写真实答案，再设计读者可见证据和当时的合理解释。可用形式：

- 物件磨损、票据日期、称谓、时间缺口、角色对小事的异常反应。
- 反复出现却发生变化的意象；“相同句子”要随关系和处境改意。
- 证词与行动不匹配，或者正确事实被错解释。
- 对承诺的兑现，让早先不起眼的选择在后续发挥作用。

误导有来源、有角色利益、有可辨瑕疵。叙述者不能把事实直接说假再无交代地翻案；有限视角可漏看，但不能隐瞒自己刚作出的核心决定。预言、梦境和规则说明不应承担所有铺垫。

每条核心伏笔建 ID：首次位置、表层含义、真实用途、读者已见证据、谁知道、计划兑现章区间、实际进展。揭晓时检查“读者回看能否指出证据”。一条伏笔可多次推进，不能只在最后说“其实早有暗示”。

章节通常收一个近问题、推进一个远问题；不要把所有疑问留给终卷。定期筛查过期线索：补推进、安排兑现或明确作废理由，不能用新谜题淹没遗忘。
