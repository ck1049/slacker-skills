# 题材、人群与原创设计

## 分类是选择工具

男频/女频是发行与阅读期待维度，不等于所有男性只读升级、所有女性只读爱情。先确定年龄、已有阅读经验、阅读场景、情绪期待和愿意接受的复杂度；同一题材可采取不同重心。没有实时市场数据时，把判断称为创作定位，不称为市场调研结论。

| 题材/方向 | 可以承诺的体验 | 有续航的冲突来源 | 常见失效及修正 |
| --- | --- | --- | --- |
| 武侠 | 身体技艺、江湖关系、义与利 | 师承、信誉、地域势力、承诺 | 招式名称代替交手；写距离、策略、代价和人情 |
| 玄幻/奇幻 | 陌生世界、探索、规则成长 | 资源分配、制度、文化和力量限制 | 换地图重复打脸；新地区改变关系和价值选择 |
| 修真/仙侠 | 长时间尺度、求道与代价 | 修行伦理、传承、寿命、凡俗牵连 | 数值升级覆盖全部；安排无法靠境界解决的难题 |
| 都市/职业 | 日常可感、能力与尊严 | 工序、团队、客户、家庭、制度 | 主角全能而同行低智；每个人有合理专业边界 |
| 悬疑/推理 | 读者推断、认知重组 | 证据、动机、时序和解释竞争 | 藏关键事实后揭底；提前给可辨证据 |
| 都市异闻/规则幻想 | 熟悉生活中的异常 | 稀缺规则、调查、公共后果 | 规则临时加码；预先冻结异常边界和失败例 |
| 科幻 | 技术或社会假设的后果 | 系统限制、利益、未知与伦理 | 名词堆砌；一个假设贯穿生活与选择 |
| 历史/架空 | 制度博弈、文明处境 | 财政、地理、军政、阶层与个人 | 现代常识无条件碾压；区分查证与架空设定 |
| 战争/军事 | 团队、压力、战略代价 | 补给、情报、指挥和生存 | 全靠个人战力；核查角色位置和行动后果 |
| 末世/生存 | 危机应对、组织与信任 | 水、食物、医疗、秩序和分工 | 无限掠夺循环；让合作与资源选择有成本 |
| 游戏/电竞/竞技 | 技艺进步、竞争与协作 | 赛制、对手策略、团队磨合 | 把战报当戏；赛前目标与赛后关系都改变 |
| 无限流/闯关 | 多场景探索与解谜 | 跨关目标、机制组合、团队秘密 | 无主线副本堆积；每关改变长期问题 |
| 恋爱/言情/婚恋 | 亲密关系、理解与选择 | 需求差异、社会处境、边界 | 误会可一句话解开却拖几十章；给真实沟通成本 |
| 古言/宫廷/权谋 | 关系与制度交锋 | 身份、家族、合法性、资源 | 后宅只剩争宠；写实际利益与人物事业 |
| 青春/校园/成长 | 身份形成、友情、第一次选择 | 家庭期待、能力、群体和未来 | 未成年人关系成人化；维护相应年龄和尺度 |
| 家庭/群像/现实 | 多个自洽的人互相影响 | 照护、劳动、金钱、记忆 | 支线互不相干；安排共享资源与后果 |
| 轻喜剧/生活流 | 陪伴、观察与情境喜剧 | 小目标、人格差异、关系修复 | 连续段子无进展；让笑话改变当场关系 |
| 冒险/旅行/混合类型 | 新环境、互补团队、发现 | 地理、文化、物件与任务冲突 | 只剩景点介绍；环境强迫人物选择 |

混合题材明确主承诺、辅助机制和禁用项。例如“都市职业 × 公平悬疑”以职业选择推进谜题，不同时承诺无限升级、恋爱后宫、末世战争和硬核推理。开篇与后续都需兑现主承诺。

## 参考技法，建立自己的表达规则

参考单每项记录作品名、实际看过的材料/章节、学什么、不学什么和本作转换。如果只是常识层面的讨论，明确写“高层技法讨论，未作本轮逐章研究”，不伪造精读或全网查重。

可用的高层方向：

- 《红楼梦》：观察日常物件、说话分寸如何显出关系；本作另写人物、社会结构与情境。
- 《三国演义》：观察多方目标交错与行动后果；不用对应人物替换和同一事件链。
- 《西游记》：观察奇观与现实欲望的映照；不移植师徒组合、标志能力或章节冒险。
- 推理经典：观察可回溯的线索与解释竞争；自行设计动机、证据、时间线和解法。

不能从“学习复仇叙事”转为照搬复仇对象、入局路线、关键反转和结局；不能摘取现成译文、小说段落做词库。“参考了很多书”不是原创证据。

## 原创差异审查

先列本题材最容易滑入的惯例，再比较：

1. 核心机制：它为何在这个世界发生，谁能接近，谁被排除？
2. 代价：失去什么，谁承担，能否转嫁，是否不可逆？
3. 主角：职业/出身是否真正改变观察、方法和利益，而不是皮肤？
4. 关系：人物各自的目标如何使盟友也发生有理由的分歧？
5. 冲突：胜利除了战力与财富，还必须解决哪种矛盾？
6. 意象与语言：来自什么生活经验，有没有不可替换的物件？
7. 终点：结局怎样由这组机制与选择推导，不能套给任意主角？

每项给一个会在剧情中发生的例子；发现与参考作品重合的独特组合，就重构因果和关系。查重工具只能辅助排查文本重合，不能证明没有剧情抄袭；未覆盖全部作品不能承诺绝对无相似。
