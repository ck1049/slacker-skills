# 规划、压力测试与冻结

## 规划规模

短篇先明确中心冲突、关键选择和结尾，世界只定义会影响本篇的规则。中长篇准备全书因果骨架、卷级转折、支线闭合、核心真相与结局，再细化前一卷与最近几章。超长连载冻结阶段目标与底层规则，预留已定义的扩展空间，不假装能提前锁死每句对白。

总长度是估算，可按审改后的实际章节长度调整；增加篇幅不得变成重复冲突。副业起步给出总量、每周可用时间、单章写作/审改工时、存稿缓冲和停更处理，不编造收入预测。产量经过实际试写后修正。

## 世界观最小充分集

| 模块 | 必答问题 | 正文检验 |
| --- | --- | --- |
| 底层机制 | 起源、可观测证据、触发条件、适用范围 | 主角如何发现而非作者讲解 |
| 能力/资源 | 如何获得、谁垄断、增长上限、失效条件 | 为什么不能反复刷同一解法 |
| 代价 | 即时/长期成本、风险、不可逆项 | 首次使用就让代价有可见证据 |
| 制度/经济 | 权力、劳动、交换、惩罚、弱者处境 | 正常人如何在此谋生 |
| 时空 | 地图尺度、路程、昼夜、通信、历法 | 同时发生的线能否相遇 |
| 认知 | 谁知道规则，信息如何传播/隐藏 | 对手为什么没利用明显漏洞 |
| 禁止事项 | 不可复活、不可无限复制等作品硬边界 | 高潮不能突然越过禁区 |

起源可对角色保密，但会影响推理的真实答案必须先在作者文档里确定。“未知”是人物状态，不是作者随时改规则的许可证。

每条核心规则做三种压力测试：

- 正常：一个资源合理、动机清楚的角色如何成功？
- 极限：多人、跨地点、时间边界、物件损毁或信息外传时会怎样？
- 失败：资源不够、条件缺失、作弊或强行越界怎样失败，留下什么后果？

任何补充说明都要检查它是否使旧代价失效。把“强者为什么不早解决”“为何不能报警/沟通/出售能力”“敌人怎样合理反制”写入压力测试。

## 人物与全书因果

人物弧线写成“原有应对方式—获得过好处—因此伤害了谁—何时失效—付什么代价学会新方法”，不只写性格形容词。外部目标与内部问题彼此牵扯。反派可以错，但不能为衬托主角永久犯低级错误；配角不能只有送情报、爱主角和死给主角看三种用途。

大纲中的关键节拍用因果连接：因为上一选择产生了某后果，所以人物进入新处境；他选择某方法，却失去某资源，因此下次不能照旧。对每卷问：删掉它，全书是否仍能毫无影响地到达结局？能则重构该卷。

支线表至少记录独立目标、起点、变化、与主线交换的资源/信息、关键交汇、收束和全书作用。支线不要求每章出现，也不能用“以后再说”无限延期。人物弧线与事件线不重复算作两条独立剧情；但它们可为聚焦章提供不同层次。

## 开写前验收

- 故事承诺与目标读者相符，核心机制有区别，主要人物能持续作选择。
- 已确定全书关键真相、高潮解法、结局和必要伏笔；不是先写谜面再临时找答案。
- 第一卷有完整起落，前几章能在行动中引出机制，避免介绍百科。
- 规则压力测试无已知致命漏洞；重要专业事实已核查或明确架空范围。
- 主角并非所有领域全能，敌我都有可用信息与限制。
- 原创、视角、时间线、主支线和目标尺度审查有记录。

记录本轮判断、实际发现与修正后冻结。没有工具支持不同审读者时可以分轮自审，但须说明读者吸引力仍待外部反馈。

## 变更纪律

冻结层：底层规则、主要真相、关键历史、人物根本动机、终点方向。

可调层：尚未定稿的场景顺序、对白、过场、次要人物、章节长度与局部表达；变化若影响冻结层仍须走变更单。

变更单记录编号、旧/新内容、问题证据、为何不能局部修、受影响章节/台账/伏笔、是否已发布、迁移方式和复核结论。用户已经授权自主创作时可自主作有记录的必要调整；涉及用户明确限制或已发布文本处置时遵从原授权，不随意扩大范围。
