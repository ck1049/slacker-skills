# 文笔、细节与条件词库

词库是观察起点。每次只选与视角、情境、人物和功能相关的项，再换成现场独有的表达。不会因为替换“漂亮”为“五官精致”就改善人物；不从现有小说抽取句子拼贴。专业细节先核实，不知道的材料、维修或医学程序不要装作事实。

## 描写转换

空泛：他很疲惫，却仍然充满责任感。

具体：他把杯底最后一点水倒进盖子，喝完才发现盐已经沉在底下。电话再响时，他先看了一眼墙上没走的钟。

这段提供身体、物件和选择，不把所有疲惫的人都写成相同动作。需要交代“连续值班三夜”时可直接写一句事实，毋须每条信息都表演一遍。

描写的优先顺序：作用 → 可见特征 → 独有历史/关系 → 必要修辞。修辞要有同一感官或具体结构上的对应；同一短段避免灯光像刀、雨像针、风像兽三个方向互相争夺注意力。

## 外貌、动作与个体辨识

| 方向 | 可观察细节 | 情境与用途 |
| --- | --- | --- |
| 发型 | 发际短茬、压帽痕、碎发贴额、分缝偏向、扎发松紧 | 职业、刚完成的动作、时间与维护习惯；不凭发色断性格 |
| 五官 | 眉尾缺口、鼻梁压痕、唇边细裂、牙齿不齐、笑时露出的旧伤 | 相认、生活压力、动作后果；避免连续五项盘点 |
| 脸型/肤色 | 瘦削颊线、下颌收紧、晒色分界、眼下暗影 | 光线和当时状态；不把骨相当善恶证据 |
| 身材/姿态 | 长期提重物的一侧肩、坐姿护腰、步幅、站立支点 | 技能、伤势、习惯；避免靠体型评判人格 |
| 衣着 | 袖口盐渍、衣领翻边、补缝线色、纽扣来源、雨后布料重量 | 经济、劳动、保护对象与生活历史 |
| 眼神 | 先看出口、跳过某张脸、跟住某只手、对焦后移开 | 信息任务与不愿承认的关系；“目光深邃”不足以说明意图 |
| 手与小动作 | 指腹茧、握杯位置、收好小票、拉平一条折痕、说话前整理工具 | 可在后续发生变化的行为，不给每句对白配小动作 |
| 声音 | 气息长度、回话延迟、句尾收断、避开称呼、同一句话对不同人的音量 | 身份与当场态度；不用单一嗓音描述覆盖全部情绪 |

## 道具、材质和场景

| 方向 | 观察选项 | 叙事作用 |
| --- | --- | --- |
| 金属 | 磕痕、锈从接缝扩散、镀层掉色、温差、振动 | 使用历史、损毁、触感与安全；先区分材料 |
| 木/纸/布 | 纤维方向、吸水翘边、折痕、油渍、修补、褪色 | 时间、保存方式、身份和情感价值 |
| 玻璃/陶/塑料 | 雾气、透光差、釉裂、刮痕、应力泛白、边缘毛刺 | 可辨异常、真假、握持和照明影响 |
| 武器/工具 | 重心、握柄磨损、配件缺口、携带方式、使用限制 | 方法和成本；不把名称表当动作戏 |
| 建筑/街巷 | 出入口、楼梯宽度、遮挡、声源、地面坡度、公共与私人空间 | 场面走位、逃离与相遇条件 |
| 家庭/工作室 | 谁坐哪里、谁保留旧物、抽屉是否上锁、工序摆放 | 权力、习惯、缺席者；不堆家具清单 |
| 自然/天气 | 水沿哪里流、风被什么挡住、天色变化、植物季节 | 影响选择和计时；天气不必永远配合情绪 |
| 气味/温度/声音 | 热油、潮纸、洗涤剂、余温、迟到的回声、机械停转后的安静 | 建立空间和变化；不虚构材料气味与事实 |

增加自己的词库时记录场景来源、适用条件、人物视角、用于什么和反例。把人物有意义的习惯留在人设卡，把通用观察放在词库，不将几十个“漂亮的词”当固定替换表。

## 白描、修辞和语言层次

- 行动紧迫时优先清楚的主语、动词和空间；转折点可用一短句停住。
- 静态片段让一个有历史的物件承受情绪，不必同时描写五种感官。
- 比喻来自人物认识的世界；修灯工、医生、少年不会无条件使用相同术语和联想。
- 隐喻先有实际物件/行为，再有意义变化；结尾不要替读者讲解全部象征。
- 古风允许现代读者读得懂的节奏，不靠“尔等”“桀桀”“恐怖如斯”构成类型感。
- 职业和生活细节不能总是灰暗；一个人保养工具、调好汤味、用笨办法照顾别人同样构成质感。

## 删水与俗套诊断

重点圈出重复情绪命名、重复世界说明、同一意义的多句比喻、无信息的动作、连串“其实/似乎/某种/不由得/仿佛”及反复对读者解释。不能机械禁词：保留确实表达不确定性、人物犹疑或节奏的用法。

将“震惊—众人不信—展示—全场跪服”的重复结构、“恶毒配角主动泄底”、动机不明的为爱牺牲、无后果开挂和“女人只作奖励”列为结构问题，不能只换形容词修补。审稿用段落后果证明其作用，不设置字数越少越好的删稿指标。
