# 逐章质量门禁

目标是发现并修复具体阅读问题。自审、不同审读者的编辑复核和真实读者反馈分开标注；分数是编辑标尺，不是客观文学真理、签约预测或抄袭检测结果。

## 四轮检查

1. **故事工程**：按冻结设定和上一章实际状态复算时间、空间、身份、知识、物件、能力、代价；检查动作因果及人物选择。
2. **戏剧与阅读**：主推进是否成立，支线是否相互作用，场景是否改变局面，局部兑现与结尾问题是否具体。
3. **语言与人物**：段落视角、对白意图、个体差异、细节功能、修辞对应、重复解释、空泛心理、说明过载。
4. **反对意见**：从挑剔读者角度找最牵强的一处、最套路的一处、最容易误解的一处；复查原创边界、目标尺度和未兑现承诺。

先完整读一遍，再逐段标问题。即使创作人与审稿人相同，也按独立任务分轮，不用“我写得很好”概括；不能声称完成了独立审稿。

## 阻断项

| 项 | 例子 | 处理 |
| --- | --- | --- |
| 原创违规 | 按参考作事件次序换姓名、复用专属能力组合、复制句段 | 重构相关因果与表达，复查邻近段落 |
| 硬规则破坏 | 宣称不能复活却无铺垫复活，代价被免费重置 | 在原规则内解场或走正式变更，不能直接定稿 |
| 连续性硬错 | 死者无解释行动、已损毁物件完好、人物知道没获知的信息 | 按正文证据修状态与台账 |
| 关键因果不成立 | 对手只为输而放弃明显可行方案、巧合代替高潮解法 | 改目标/条件/行动，使结果来自选择 |
| 核心谜题不公平 | 最后新增此前没有可能发现的规则，视角隐瞒当场已知答案 | 提前呈现证据或改变揭晓方式 |
| 尺度违背 | 与目标读者/用户边界冲突的内容 | 按既定边界改稿 |

阻断项存在时结论只能“未通过”。用户要求保存草稿时可保存，但不得把草稿的新事实当定稿继承。阻断不代表停止一切工作；可继续不依赖问题的规划与修稿。

## 定性检查与可选评分

按 1—5 分给下列维度评分时必须同时给证据：1=关键功能失败；2=明显影响阅读；3=基本成立但有待修问题；4=功能清楚且有作品辨识度；5=具体、可信且相互增益。无相关项填“不适用”及理由，不强迫恋爱戏包含战斗。

| 维度 | 证据问题 |
| --- | --- |
| 因果与规则 | 转折从谁的什么选择而来？代价在哪个动作中发生？ |
| 人物与关系 | 换成另一个角色是否还能原样说/做？各自合理利益是什么？ |
| 主支线与节奏 | 哪条线影响另一条线？删哪一场会丢什么？ |
| 悬念与兑现 | 读者已获得什么证据？本章解决了什么小问题？ |
| 细节与文笔 | 具体物件怎样参与戏？哪个修辞多余或视角不合？ |
| 对白与视角 | 有无大家轮流向读者讲课？知识是否越过人物边界？ |
| 原创与成熟度 | 有无换皮组合、无后果羞辱、刻板人物或为了反转降智？ |

通过条件：无阻断项；影响阅读的主要问题已修复且复验；因果、人物、连续性、原创尺度等核心功能成立；记录剩余一般建议。数字平均分不得绕过任何条件。所有维度打满分不构成验收。

## 问题必须可定位

问题单写章节、场景/段落锚点、简短原句、等级、失败机制、修改方案、实际修改和复验结果。建议中的“文笔再细腻一点”“增加爽感”不可直接执行，改成“让鞋里的水在走路时产生实际不便，替换三句紧张总结”等可验证目标。

初稿修正后再全章读一遍，避免删除一句解释后线索看不懂，或者把代价推迟后破坏下一章。最终评审绑定当前文本版本/文件摘要；后续修改正文要重验受影响项目，不能沿用旧分数。

## 卷级和外部反馈

每卷结束查看支线收束、重复结构、力量膨胀、人物声音、伏笔过期、主题是否由选择体现。真实读者反馈到来时记录样本和具体反应，区分个人偏好、误读、确实看不懂与设定漏洞；不要让每条意见推翻冻结规则，也不把小样的好评当市场验证。
