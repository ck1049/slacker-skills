# 多线章节、悬念与读者参与

## 从事件数量转向因果密度

章节丰富不等于同时发生很多无关事件。先确定读者本章等待的主问题，再安排另一个人的目标或日常现实对它形成压力。一次维修既可推进异常调查，又可影响补助争议和两个人的信任；如果每条线删除后都不影响其他线，往往只是拼盘。

常见交织方式：

| 结构 | 使用条件 | 避免 |
| --- | --- | --- |
| A 中含 B | 同一场景内任务与关系争执互相影响 | 对话只是介绍另一个故事 |
| A→B→A | 切到 B 会改变读者对 A 的理解或制造时间压力 | 每到关键处就机械切走 |
| 双线汇合 | 人物各有目标，争夺同一物件/地点/时机 | 主角碰巧捡到所有答案 |
| 后果接力 | A 的胜利变成 B 的麻烦，B 的选择回到 A | 胜利后所有人立即恢复原状 |
| 聚焦章 | 高潮、告别、关键坦白需要连续情绪 | 为凑支线打断情绪；需保留关系/代价层次 |

场景不是讨论会：有人想获得什么，有人/现实挡住他，他采取行动，结果改变下一步。开场可以平静，平静中也应存在目标或等待。省略无意义的抵达、重复问答和不会改变任何人的日常流程。

## 人物对话

各人知道不同信息、在意不同损失、需要不同结果。先写各人“想让对方做什么”，再写台词。每一句不必藏谜，但应有辨认、试探、要求、拒绝、转移、妥协或情绪作用。

区分词汇、句长、回避方式和行动习惯，不给每人一个机械口头禅。主角不是每次都最会说话；专业人物可以用简短行话，但读者通过行动知道其意义。争执允许对方有正确部分，不让反派主动发表供主角反驳的愚蠢演说。

## 悬念的四种来源

- 结果：一个已经开始的行动能否完成？先让目标和危险可感。
- 原因：确有异常证据，现有解释不能覆盖它。给可推断材料。
- 选择：两种合理需求不可兼得，人物会舍弃哪一种？
- 认知差：读者与人物分别掌握哪些信息？认知差必须来自叙述安排，而非无依据开天眼。

悬念不必全是危险或死亡。读者也会等待一次道歉、物件归还、合作条件、代价显现和一个人是否守约。埋点只呈现证据与反应，不在正文提醒“这是后来改变命运的伏笔”。

章节尾优先停在：具体行动的后果、可信的发现、必须作出的决定、兑现后的新处境。避免连续使用匿名电话、梦醒、黑影、反派笑容和“真正的故事刚刚开始”。

## 局部兑现与节奏

每章检查是否给读者一个实际所得：看懂一个机制、完成一段对峙、看见关系变化、收回一个早先承诺或获得新的可用证据。单章可以留问题，但不能整章都是预告。

紧张与缓冲相互支持：危机中一个小动作可暴露在意的人；危机后生活后果为下一场提供动力。情绪密度高的段落之后用可触碰的物件或短行动落地，不以旁白反复总结感动。

一章的主线转折、支线进展、伏笔和人物变化可以来自同一行动，不要求四场戏。审稿时问“如果删这一段，哪个后果会不成立”，而不是按支线数量评分。
